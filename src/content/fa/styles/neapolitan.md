## پیتزای آماده

پیتزای ناپولیتن وسطش نازک و نرم است و حاشیه‌ای بلند، نرم و پف‌کرده دارد. همه‌ی دماهای این سایت به درجه‌ی سانتی‌گراد است. نتیجه این‌طور است:

- **وسط:** نازک و نرم. خم می‌شود. مثل کراکر ترد نیست.
- **حاشیه (لبه‌ی پیتزا):** بلند، پرهوا و لطیف، با چند لکه‌ی قهوه‌ای تا تیره که گرما رویش می‌اندازد.
- **در خانه:** فر واقعی ناپولیتن روی {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.1 }} درجه کار می‌کند و پیتزا را در {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.1 }} ثانیه می‌پزد. فر تو تا {{ recipes.oven.max_c.value }} درجه گرم می‌شود، پس پخت {{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه طول می‌کشد. نتیجه پیتزای **به سبک ناپولیتن** است، نه خود اصلش. حاشیه کمی سفت‌تر می‌شود و رنگش کمتر تیره. ولی باز هم پیتزای خیلی خوبی است.

دستور اصلی بیشتر به طعم و بافت توجه دارد تا عددهای دقیق. همه‌ی مقدارها و زمان‌های اینجا نقطه‌ی شروع‌اند. یک بار بپز، خمیر و پوسته را نگاه کن و دفعه‌ی بعد هر چه لازم است تغییر بده.

## انتخاب تخمیر

در ناپل خمیر معمولاً {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.1 }} ساعت در دمای اتاق و با مخمر خیلی کم تخمیر می‌شود. تخمیر یعنی مخمر قند را می‌خورد و گاز و طعم می‌سازد. سه نوع تخمیر داری. تخمیر را در صفحه‌ی اصلی انتخاب می‌کنی و کارت «مواد لازم» در همین صفحه مقدارهای همان را نشان می‌دهد. برای امتحان تخمیر دیگر، بالای صفحه «تغییر» را بزن.

**تخمیر در دمای اتاق، {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت: نزدیک‌ترین به ناپل.** خمیر در دمای اتاق (حدود {{ recipes.oven.room_c.value }} درجه) ور می‌آید؛ اول یک‌تکه و بعد به شکل چونه.

- **مزیت‌ها:** در ناپل همین‌طور درستش می‌کنند. ور آمدن آرام طعم عمیقی می‌دهد.
- **عیب‌ها:** باید روزت را برنامه‌ریزی کنی و زمان‌بندی به دمای اتاقت بستگی دارد. اتاق گرم‌تر یعنی ور آمدن سریع‌تر. مقدار مخمر این تخمیر نامطمئن‌ترین مقدار این راهنماست.

**تخمیر سرد، {{ recipes.methods.cold_24h.fridge_h.value }} ساعت: برنامه‌ریزی‌اش از همه راحت‌تر است.** خمیر در یخچال (حدود {{ recipes.oven.fridge_c.range.0 }} تا {{ recipes.oven.fridge_c.range.1 }} درجه) استراحت می‌کند. مخمر آنجا آرام کار می‌کند.

- **مزیت‌ها:** طعم عمیق. اگر برنامه‌ات عوض شد، خمیر حدود یک روز بیشتر هم در یخچال می‌ماند. روز پخت کار زیادی نداری.
- **عیب‌ها:** در یخچال جا لازم داری و مقدار مخمر باید دقیق باشد. برای همین این تخمیر معمولاً از «محلول مخمر» استفاده می‌کند (وقتی لازم باشد، جدول مواد لازم ردیف «محلول مخمر» دارد).

**تخمیر گرم، 2 ساعت: وقتی عجله داری.** خمیر را درست می‌کنی و حدود دو ساعت بعد می‌پزی.

- **مزیت‌ها:** همان روز آماده است.
- **عیب‌ها:** طعمش ساده‌تر و بیشتر شبیه نان معمولی است. در بین این سه تخمیر، از همه از اصلش دورتر است.
- **دست‌کم {{ recipes.methods.warm_2h.min_pizzas }} پیتزا لازم دارد.** برای یک پیتزا مخمر خشک آن‌قدر کم می‌شود که ترازوی آشپزخانه نشانش نمی‌دهد، و این راهنما برای مخمر تازه هم همین قاعده را نگه می‌دارد.

**خلاصه:** اگر وقت داری، برای نزدیک‌ترین نتیجه تخمیر در دمای اتاق را انتخاب کن، یا برای راحت‌ترین برنامه تخمیر سرد را. اگر می‌خواهی همین امروز بخوری، تخمیر گرم هم پیتزای خوشمزه‌ای می‌دهد.

## آرد و مخمر

**آرد.** همان آرد پیتزایی را بگیر که برای پیتزای نیویورکی می‌گیری (که اغلب روی بسته‌اش «تیپو 00» نوشته شده). صفحه‌ی دستور نیویورکی در بخش «آرد و مخمر» توضیح می‌دهد پروتئین روی بسته را چطور بخوانی.

**مخمر.** کارت «مواد لازم» همان مخمری را نشان می‌دهد که در صفحه‌ی اصلی انتخاب کرده‌ای (خشک یا تازه). صفحه‌ی دستور نیویورکی در بخش «آرد و مخمر» هر دو نوع را توضیح داده است. تخمیر در دمای اتاق و تخمیر سرد معمولاً از محلول مخمر استفاده می‌کنند، چون مقدار مخمر برای ترازوی آشپزخانه خیلی کم است. مرحله‌های مخمر پایین طرز درست کردنش را می‌گویند و جدول مواد لازم نشان می‌دهد محلول لازم است یا نه.

- **شکر:** خمیر اصلی شکر ندارد. این دستور خانگی کمی شکر دارد ({{ recipes.styles.neapolitan.dough.sugar.value }}% وزن آرد؛ کارت «مواد لازم» مقدارش را به گرم نشان می‌دهد)، چون فر {{ recipes.oven.max_c.value }} درجه پیتزا را کمتر از فر واقعی ناپولیتن رنگ می‌اندازد. می‌توانی شکر را نریزی.
- **روغن:** هیچ. داخل این خمیر روغن نیست.

> Warning: مقدار مخمر نقطه‌ی شروع است، نه قانون ثابت. منبع‌ها برای یک برنامه‌ی یکسان تا {{ recipes.yeast.source_spread_x.value }} برابر با هم فرق دارند. مقدار درست به دمای اتاق یا یخچال و مخمر خودت بستگی دارد. یک بار بپز، خمیر و پوسته را نگاه کن و دفعه‌ی بعد مقدار را تغییر بده.

## تخمیر در دمای اتاق، {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت {methods=room_8_12h}

خمیر را صبح درست می‌کنی و عصر می‌پزی، یا برعکس. خمیر روی هم {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت در دمای اتاق ور می‌آید. مقدارها را از کارت «مواد لازم» همین صفحه بردار.

> Warning: دمای اتاق سرعت ور آمدن را خیلی تغییر می‌دهد. این برنامه برای اتاقی با دمای حدود {{ recipes.oven.room_c.value }} درجه است. اگر اتاق گرم‌تر از {{ recipes.styles.new_york.practice.hot_room_c.value }} درجه است، هر دو مرحله‌ی ور آمدن را کوتاه‌تر کن و حواست به خمیر باشد.

1. **مخمر را آماده کن**
   1. آب خنک (حدود {{ recipes.methods.room_8_12h.water_temp_c.value }} درجه) را در یک کاسه‌ی بزرگ بریز. هیچ‌وقت آب داغ نریز: مخمر را می‌کشد.
   2. جدول مواد لازم را نگاه کن.
      - **اگر در جدول ردیف «محلول مخمر» هست:** در یک لیوان جدا یک بسته‌ی کامل {{ recipes.yeast.solution.dry.yeast_g.value }} گرمی مخمر خشک (یا نصف یک مکعب {{ recipes.yeast.solution.fresh.cube_g.value }} گرمی مخمر تازه) را در {{ recipes.yeast.solution.dry.water_g.value }} گرم آب ولرم ({{ recipes.yeast.solution.water_temp_c.range.0 }} تا {{ recipes.yeast.solution.water_temp_c.range.1 }} درجه) هم بزن تا هیچ گلوله‌ای نماند. {{ recipes.yeast.solution.dissolve_wait_min.value }} دقیقه صبر کن و دوباره هم بزن. بعد همان مقداری را که جدول نشان می‌دهد بلافاصله در آب خمیر بریز و باقی‌مانده را دور بریز.
      - **اگر در جدول ردیف «مخمر خشک» یا «مخمر تازه» هست:** همان مقدار را وزن کن و در آب هم بزن. مخمر تازه را اول خرد کن. مخمر فوری خشک لازم نیست صبر کند.
   3. فعلاً نمک را داخل کاسه نریز: نمکی که مستقیم به مخمر برسد کارش را کند می‌کند.
   > Why: مقدار کم مخمر برای ترازوی آشپزخانه خیلی سبک است، پس به‌جایش بخشی از محلول مخمر را وزن می‌کنی. در خمیرهای بزرگ‌تر مخمر آن‌قدر هست که مستقیم وزن شود. وقتی جدول ردیف محلول مخمر دارد، وزن آن را از قبل از آب کم کرده است. نمک کار مخمر را کند می‌کند، برای همین بعداً اضافه می‌شود.

   > Tip: مخمر فوری به فعال‌سازی نیاز ندارد، پس می‌توانی از این امتحان بگذری. اگر مخمرت کهنه است یا مطمئن نیستی زنده باشد، اول امتحانش کن: کمی از آن را در یک لیوان جدا، با آب ولرم هم بزن (یک ذره شکر کمک می‌کند کف زودتر پیدا شود؛ این شکر فقط برای امتحان است) و صبر کن تا روی آب کف بیاید. چند دقیقه طول می‌کشد. اگر کف نکرد، مخمر مرده است: مخمر نو بگیر.
2. **خمیر را مخلوط کن**
   1. حدود نصف آرد را بریز و هم بزن تا مخلوط صاف شود.
   2. بعد بقیه‌ی آرد را کم‌کم بریز و بعد از هر بار هم بزن.
   3. فقط آن‌قدر هم بزن که آرد خشکی نماند. کاسه‌ات آن‌قدر بزرگ باشد که موقع هم زدن بیرون نریزد.
   > Why: آردی که کم‌کم اضافه شود یکدست خیس می‌شود، پس گلوله‌ی خشک درست نمی‌شود و مخمر در خمیر پخش می‌شود.
3. **خمیر را استراحت بده**
   روی کاسه را بپوشان و خمیر را {{ recipes.methods.room_8_12h.autolyse_min.range.0 }} تا {{ recipes.methods.room_8_12h.autolyse_min.range.1 }} دقیقه بگذار. به این استراحت «اتولیز» می‌گویند.
   > Why: آب و آنزیم‌های آرد خودبه‌خود ساختن گلوتن را شروع می‌کنند، پس ورز کمتری لازم است.
4. **نمک را اضافه کن و ورز بده**
   نمک و شکر را روی خمیر بپاش و در آن کار کن تا یکدست شود. بعد {{ recipes.methods.room_8_12h.knead_min.range.0 }} تا {{ recipes.methods.room_8_12h.knead_min.range.1 }} دقیقه ورز بده. بخش «ورز دادن» در صفحه‌ی دستور نیویورکی طرز ورز دادن را توضیح می‌دهد. روغن اضافه نکن.
   > Why: نمک گلوتن را قوی‌تر می‌کند و کار مخمر را کند می‌کند. گلوتن همان شبکه‌ی کشسانی است که گاز مخمر را نگه می‌دارد.
5. **بگذار خمیر ور بیاید**
   خمیر را در ظرف دردار بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین) و {{ recipes.methods.room_8_12h.bulk_min.value }} دقیقه، یک‌تکه، در دمای اتاق نگه دار. رویش را بپوشان تا سطحش خشک نشود.
   > Why: مخمر گاز می‌سازد و گاز خمیر را بزرگ و پف‌دار می‌کند. ور آمدن آرام در دمای اتاق طعم می‌سازد.

   > Tip: ظرفی بردار که خمیر بتواند دو برابر شود و به درِ ظرف نخورد. سطح خمیر را بیرون ظرف با چسب کاغذی یا ماژیک علامت بزن تا ببینی چقدر بزرگ شده است.
6. **خمیر را تقسیم و چونه کن**
   1. کل خمیر را روی ترازو بگذار. وزنش باید نزدیک «مجموع خمیر» در جدول مواد لازم باشد.
   2. این وزن را بر تعداد پیتزاها تقسیم کن. از خمیر تکه‌های هم‌وزن ببر.
   3. هر تکه را شکل بده: لبه‌ها را به وسط جمع کن، چونه را برگردان و با کف دست روی میز بچرخان تا سطحش کشیده و صاف شود. هر چونه را در یک ظرف دردار جدا بگذار.
   > Why: چونه‌های هم‌وزن یکنواخت می‌پزند و پیتزاهایی هم‌اندازه می‌دهند. ترازو از چشم دقیق‌تر است. سطح کشیده گاز را داخل نگه می‌دارد و چونه بعداً راحت‌تر باز می‌شود.
7. **چونه‌ها را استراحت بده**
   روی چونه‌ها را بپوشان و {{ recipes.methods.room_8_12h.final_rest_min.value }} دقیقه بگذار. کل ور آمدن، از مخلوط کردن تا پخت، {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت طول می‌کشد.
   > Why: خمیر در چونه‌ها آرام به ور آمدن ادامه می‌دهد و گلوتن شل می‌شود. چونه‌ای که استراحت کرده راحت باز می‌شود و جمع نمی‌شود.
8. **فر و سطح پخت را داغ کن**
   این کار را {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه پیش از پخت انجام بده، وقتی چونه‌ها هنوز در حال استراحت‌اند. سطح پخت (سنگ پیتزا، فولاد پخت یا سینی چدنی) را در طبقه‌ی بالای فر بگذار، یعنی حدود یک‌سوم بالایی فر. فر را روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه، با گرمای بالا و پایین و **بدون فن** تنظیم کن.
   > Why: سطحی که کامل داغ نشده، کفی رنگ‌پریده و نرم می‌دهد. گرمای بالا و پایین گرما را مستقیم از زیر به سطح پخت می‌رساند. در حالت فن، المنت پایین اغلب خاموش است و هوای در حال حرکت روی پیتزا را زودتر از کفش خشک می‌کند و رنگ می‌اندازد. اگر فرت حالت پیتزا دارد (فن همراه با گرمای پایین)، می‌توانی امتحانش کنی و حواست به روی پیتزا باشد.
9. **چونه را باز کن**
   این کار را فقط وقتی فر داغ شد انجام بده. روی بقیه‌ی چونه‌ها پوشیده بماند.
   1. حدود {{ recipes.styles.new_york.practice.bench_flour_g.value }} گرم آرد (یا سمولینا) روی میز بپاش، چونه را رویش بگذار و با نوک انگشت‌ها از وسط به بیرون فشار بده. **به حاشیه‌ی {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متری دست نزن.**
   2. خمیر را با دو دست بکش و بچرخان تا به اندازه‌ای برسد که در صفحه‌ی اصلی انتخاب کرده‌ای (بالای همین صفحه نوشته شده).
   3. اگر خمیر جمع شد، بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند.
   > Why: حاشیه‌ی دست‌نخورده هوایش را نگه می‌دارد، پس در فر پف می‌کند. حاشیه‌ی بلند و نرم نشانه‌ی پیتزای ناپولیتن است.

   > Warning: از وردنه استفاده نکن. وردنه هوای خمیر را بیرون می‌دهد و حاشیه پف نمی‌کند.
10. **روی پیتزا را بچین**
    ساده بچین.
    1. یک لایه‌ی نازک سس پخش کن و حاشیه را (حدود {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر) خالی بگذار.
    2. پنیر و هر چیز دیگری که دوست داری رویش بریز.
    3. بعد حاشیه را با کمی روغن زیتون چرب کن. روی پیتزا زیاد مواد نریز. سریع کار کن، چون خمیری که روی تخته یا کاغذ معطل بماند می‌چسبد.
    > Why: مواد رویی سبک اجازه می‌دهند بخار بیرون برود، پس وسط پیتزا به‌جای خیس ماندن سفت می‌شود. مواد زیاد پیتزا را سنگین می‌کند و لغزاندنش سخت می‌شود. مواد آبدار را اول با دستمال خشک کن و پنیر رنده‌شده‌ی خشک بریز.
11. **پیتزا را داخل فر بلغزان**
    آن را از روی تخته یا کفگیر پیتزا (پاروی تخت مخصوص پیتزا) روی سطح پخت ببر. روی تخته کمی سمولینا یا آرد بپاش، یا اگر ترجیح می‌دهی از کاغذ روغنی استفاده کن (یادداشت ایمنی پایین را ببین).
    > Why: هر بار که در فر را باز می‌کنی، گرما از دست می‌رود. سریع باش.

    > Safety: استفاده از کاغذ روغنی (کاغذ مخصوص فر) انتخاب خودت است. بدون کاغذ: خمیر را روی تخته یا کفگیر پیتزایی که کمی سمولینا یا آرد رویش پاشیده‌ای باز کن، بعد روی سطح داغ بلغزان. با کاغذ: حداکثر دمای چاپ‌شده روی بسته را ببین. دمای مجاز خیلی از کاغذها {{ recipes.safety.parchment_max_c.value }} درجه است که از دمای این فر کمتر است. کاغذ را از المنت‌ها و دیواره‌های فر دور نگه دار و لبه‌های اضافی‌اش را قیچی کن. از کاغذ مومی (کاغذی که لایه‌ی موم دارد و برای فر ساخته نشده) استفاده نکن. اگر دمای مجاز کاغذت از دمای فر کمتر است، بعد از {{ recipes.safety.parchment_pull_min.range.0 }} تا {{ recipes.safety.parchment_pull_min.range.1 }} دقیقه‌ی اول، وقتی کف پیتزا خودش را گرفت، کاغذ را از زیرش بیرون بکش. اگر از کاغذ استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Safety: روغن زیتون فرابکر از حدود {{ recipes.safety.evoo_smoke_c.range.0 }} تا {{ recipes.safety.evoo_smoke_c.range.1 }} درجه شروع به دود کردن می‌کند و این فر روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه است. سطح پخت داغ را روغن نزن. داخل این خمیر روغن نیست. برای حاشیه فقط یک لایه‌ی نازک بزن و روغن زیتون تصفیه‌شده یا سبک انتخاب کن، چون کمتر دود می‌کند.

    > Safety: دستکش فر بپوش. طبقه‌ی فر را فقط کمی بیرون بکش تا پیتزا را رویش بلغزانی، و هیچ‌وقت به سطح پخت دست نزن؛ تا مدت زیادی بعد از خاموش کردن فر هم داغ می‌ماند.
12. **بپز**
    {{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه با گرمای بالا و پایین بپز. {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخر گریل را روشن کن تا روی پیتزا و حاشیه رنگ بگیرد. کنار فر بمان و حواست به پیتزا باشد. پیتزا روی هم نباید بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه زیر گریل بماند. اگر از کاغذ روغنی استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.
    > Why: فر {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه از بالا گرمای کافی نمی‌دهد. فر واقعی ناپولیتن خیلی داغ‌تر است، پس گریل بخشی از آن گرما را جبران می‌کند.

    > Tip: پیتزا وقتی آماده است که حاشیه پف کرده و لکه‌های قهوه‌ای تا تیره دارد و کفش سفت شده است. پیش از اینکه لکه‌ها سیاه شوند، پیتزا را بیرون بیاور.
13. **پیتزا را دربیاور**
    اگر دوست داری، ریحان تازه و کمی روغن زیتون رویش بریز.
14. **برای پیتزای دوم صبر کن**
    روی چونه‌اش را بپوشان تا پیتزای اول بیرون بیاید و سطح پخت دوباره داغ شود. این کار حدود {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.0 }} تا {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.1 }} دقیقه طول می‌کشد. فقط بعد از آن چونه را باز کن.
    > Why: خمیری که روی تخته یا کاغذ معطل بماند خیس می‌شود و می‌چسبد.

## تخمیر سرد {methods=cold_24h}

خمیر را یک روز پیش از پخت درست می‌کنی. مقدارها را از کارت «مواد لازم» همین صفحه بردار. مرحله‌ها تا «خمیر را سرد کن» مال روز اول است و مرحله‌ها از «خمیر را از یخچال دربیاور» به بعد مال روز پخت.

> Tip: اگر جدول ردیف محلول مخمر دارد، آن را درست پیش از استفاده آماده کن و درست پیش از برداشتن مقدار لازم دوباره هم بزن، چون مخمر ته ظرف می‌نشیند. باقی‌مانده‌اش را دور بریز. هیچ منبعی نمی‌گوید محلول مخمر تا کی سالم می‌ماند، برای همین این راهنما مدت نگهداری برایش نمی‌دهد.

1. **مخمر را آماده کن**
   1. آب سرد (حدود {{ recipes.methods.cold_24h.water_temp_c.value }} درجه) را در یک کاسه‌ی بزرگ بریز.
   2. جدول مواد لازم را نگاه کن.
      - **اگر در جدول ردیف «محلول مخمر» هست:** در یک لیوان جدا یک بسته‌ی کامل {{ recipes.yeast.solution.dry.yeast_g.value }} گرمی مخمر خشک (یا نصف یک مکعب {{ recipes.yeast.solution.fresh.cube_g.value }} گرمی مخمر تازه) را در {{ recipes.yeast.solution.dry.water_g.value }} گرم آب ولرم ({{ recipes.yeast.solution.water_temp_c.range.0 }} تا {{ recipes.yeast.solution.water_temp_c.range.1 }} درجه) هم بزن تا هیچ گلوله‌ای نماند. {{ recipes.yeast.solution.dissolve_wait_min.value }} دقیقه صبر کن و دوباره هم بزن. بعد همان مقداری را که جدول نشان می‌دهد بلافاصله در آب خمیر بریز و باقی‌مانده را دور بریز.
      - **اگر در جدول ردیف «مخمر خشک» یا «مخمر تازه» هست:** همان مقدار را وزن کن و در آب هم بزن. مخمر تازه را اول خرد کن. مخمر فوری خشک لازم نیست صبر کند.
   3. فعلاً نمک را داخل کاسه نریز: نمکی که مستقیم به مخمر برسد کارش را کند می‌کند.
   > Why: مقدار کم مخمر برای ترازوی آشپزخانه خیلی سبک است، پس به‌جایش بخشی از محلول مخمر را وزن می‌کنی. در خمیرهای بزرگ‌تر مخمر آن‌قدر هست که مستقیم وزن شود. وقتی جدول ردیف محلول مخمر دارد، وزن آن را از قبل از آب سرد کم کرده است. نمک کار مخمر را کند می‌کند، برای همین بعداً اضافه می‌شود.

   > Tip: مخمر فوری به فعال‌سازی نیاز ندارد، پس می‌توانی از این امتحان بگذری. اگر مخمرت کهنه است یا مطمئن نیستی زنده باشد، اول امتحانش کن: کمی از آن را در یک لیوان جدا، با آب ولرم هم بزن (یک ذره شکر کمک می‌کند کف زودتر پیدا شود؛ این شکر فقط برای امتحان است) و صبر کن تا روی آب کف بیاید. چند دقیقه طول می‌کشد. اگر کف نکرد، مخمر مرده است: مخمر نو بگیر.
2. **خمیر را مخلوط کن**
   1. حدود نصف آرد را بریز و هم بزن تا مخلوط صاف شود.
   2. بعد بقیه‌ی آرد را کم‌کم بریز و بعد از هر بار هم بزن.
   3. فقط آن‌قدر هم بزن که آرد خشکی نماند. کاسه‌ات آن‌قدر بزرگ باشد که موقع هم زدن بیرون نریزد. خمیر خنک می‌شود، نه سرد؛ اشکالی ندارد.
   > Why: آردی که کم‌کم اضافه شود یکدست خیس می‌شود، پس گلوله‌ی خشک درست نمی‌شود و مخمر در خمیر پخش می‌شود.
3. **خمیر را استراحت بده**
   روی کاسه را بپوشان و خمیر را {{ recipes.methods.cold_24h.autolyse_min.range.0 }} تا {{ recipes.methods.cold_24h.autolyse_min.range.1 }} دقیقه بگذار. به این استراحت «اتولیز» می‌گویند.
   > Why: آب و آنزیم‌های آرد خودبه‌خود ساختن گلوتن را شروع می‌کنند، پس ورز کمتری لازم است.
4. **نمک را اضافه کن و ورز بده**
   نمک و شکر را روی خمیر بپاش و در آن کار کن تا یکدست شود. بعد {{ recipes.methods.cold_24h.knead_min.range.0 }} تا {{ recipes.methods.cold_24h.knead_min.range.1 }} دقیقه ورز بده. بخش «ورز دادن» در صفحه‌ی دستور نیویورکی طرز ورز دادن را توضیح می‌دهد، و اینکه چطور به‌جایش از کشیدن و تا کردن استفاده کنی. روغن اضافه نکن.
   > Why: نمک گلوتن را قوی‌تر می‌کند و کار مخمر را کند می‌کند.
5. **بگذار خمیر ور بیاید**
   خمیر را با روی پوشیده در دمای اتاق (حدود {{ recipes.oven.room_c.value }} درجه) نگه دار، {{ recipes.methods.cold_24h.room_rest_min.range.0 }} تا {{ recipes.methods.cold_24h.room_rest_min.range.1 }} دقیقه، تا حدود {{ recipes.styles.new_york.practice.cold_rise_pct.value }}% بزرگ‌تر شود. اگر کشیدن و تا کردن را انتخاب کرده‌ای، در همین مدت {{ recipes.methods.cold_24h.stretch_fold.rounds.value }} دور انجام بده، از همین حالا و هر {{ recipes.methods.cold_24h.stretch_fold.gap_min.value }} دقیقه یک دور، و بگذار ور آمدن کامل {{ recipes.methods.cold_24h.room_rest_min.range.1 }} دقیقه طول بکشد.
   > Why: مخمر پیش از رفتن به سرما یک شروع گرم و کوتاه لازم دارد.

   > Tip: ظرفی بردار که خمیر بتواند دو برابر شود و به درِ ظرف نخورد. سطح خمیر را بیرون ظرف با چسب کاغذی یا ماژیک علامت بزن تا ببینی چقدر بزرگ شده است.
6. **خمیر را تقسیم و چونه کن**
   1. کل خمیر را روی ترازو بگذار. وزنش باید نزدیک «مجموع خمیر» در جدول مواد لازم باشد.
   2. این وزن را بر تعداد پیتزاها تقسیم کن. از خمیر تکه‌های هم‌وزن ببر.
   3. هر تکه را شکل بده: لبه‌ها را به وسط جمع کن، چونه را برگردان و با کف دست روی میز بچرخان تا سطحش کشیده و صاف شود. هر چونه را در یک ظرف دردار جدا بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین).
   > Why: چونه‌های هم‌وزن یکنواخت می‌پزند و پیتزاهایی هم‌اندازه می‌دهند. ترازو از چشم دقیق‌تر است. سطح کشیده گاز را داخل نگه می‌دارد و چونه بعداً راحت‌تر باز می‌شود.
7. **خمیر را سرد کن**
   آن‌ها را {{ recipes.methods.cold_24h.fridge_h.value }} ساعت آنجا نگه دار.
   > Why: در یخچال مخمر آرام کار می‌کند و آنزیم‌ها فرصت دارند طعم بسازند. نتیجه طعم عمیق‌تر و رنگ‌گیری بهتر است.
8. **خمیر را از یخچال دربیاور**
   این کار را روز پخت، {{ recipes.methods.cold_24h.take_out_lead_min.range.0 }} تا {{ recipes.methods.cold_24h.take_out_lead_min.range.1 }} دقیقه پیش از باز کردن خمیر انجام بده. در ظرف را باز نکن.
   > Why: خمیر سرد کش نمی‌آید و پاره می‌شود. این رایج‌ترین اشتباه در تخمیر سرد است.
9. **فر و سطح پخت را داغ کن**
   این کار را {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه پیش از پخت انجام بده، همان وقتی که خمیر دارد از سرما درمی‌آید. سطح پخت (سنگ پیتزا، فولاد پخت یا سینی چدنی) را در طبقه‌ی بالای فر بگذار، یعنی حدود یک‌سوم بالایی فر. فر را روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه، با گرمای بالا و پایین و **بدون فن** تنظیم کن.
   > Why: سطحی که کامل داغ نشده، کفی رنگ‌پریده و نرم می‌دهد. گرمای بالا و پایین گرما را مستقیم از زیر به سطح پخت می‌رساند. در حالت فن، المنت پایین اغلب خاموش است و هوای در حال حرکت روی پیتزا را زودتر از کفش خشک می‌کند و رنگ می‌اندازد. اگر فرت حالت پیتزا دارد (فن همراه با گرمای پایین)، می‌توانی امتحانش کنی و حواست به روی پیتزا باشد.
10. **چونه را باز کن**
    این کار را فقط وقتی فر داغ شد انجام بده. روی بقیه‌ی چونه‌ها پوشیده بماند.
    1. حدود {{ recipes.styles.new_york.practice.bench_flour_g.value }} گرم آرد (یا سمولینا) روی میز بپاش، چونه را رویش بگذار و با نوک انگشت‌ها از وسط به بیرون فشار بده. **به حاشیه‌ی {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متری دست نزن.**
    2. خمیر را با دو دست بکش و بچرخان تا به اندازه‌ای برسد که در صفحه‌ی اصلی انتخاب کرده‌ای (بالای همین صفحه نوشته شده).
    3. اگر خمیر جمع شد، بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند.
    > Why: حاشیه‌ی دست‌نخورده هوایش را نگه می‌دارد، پس در فر پف می‌کند. حاشیه‌ی بلند و نرم نشانه‌ی پیتزای ناپولیتن است.

    > Warning: از وردنه استفاده نکن. وردنه هوای خمیر را بیرون می‌دهد و حاشیه پف نمی‌کند.
11. **روی پیتزا را بچین**
    ساده بچین.
    1. یک لایه‌ی نازک سس پخش کن و حاشیه را (حدود {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر) خالی بگذار.
    2. پنیر و هر چیز دیگری که دوست داری رویش بریز.
    3. بعد حاشیه را با کمی روغن زیتون چرب کن. روی پیتزا زیاد مواد نریز. سریع کار کن، چون خمیری که روی تخته یا کاغذ معطل بماند می‌چسبد.
    > Why: مواد رویی سبک اجازه می‌دهند بخار بیرون برود، پس وسط پیتزا به‌جای خیس ماندن سفت می‌شود. مواد زیاد پیتزا را سنگین می‌کند و لغزاندنش سخت می‌شود. مواد آبدار را اول با دستمال خشک کن و پنیر رنده‌شده‌ی خشک بریز.
12. **پیتزا را داخل فر بلغزان**
    آن را از روی تخته یا کفگیر پیتزا (پاروی تخت مخصوص پیتزا) روی سطح پخت ببر. روی تخته کمی سمولینا یا آرد بپاش، یا اگر ترجیح می‌دهی از کاغذ روغنی استفاده کن (یادداشت ایمنی پایین را ببین).
    > Why: هر بار که در فر را باز می‌کنی، گرما از دست می‌رود. سریع باش.

    > Safety: استفاده از کاغذ روغنی (کاغذ مخصوص فر) انتخاب خودت است. بدون کاغذ: خمیر را روی تخته یا کفگیر پیتزایی که کمی سمولینا یا آرد رویش پاشیده‌ای باز کن، بعد روی سطح داغ بلغزان. با کاغذ: حداکثر دمای چاپ‌شده روی بسته را ببین. دمای مجاز خیلی از کاغذها {{ recipes.safety.parchment_max_c.value }} درجه است که از دمای این فر کمتر است. کاغذ را از المنت‌ها و دیواره‌های فر دور نگه دار و لبه‌های اضافی‌اش را قیچی کن. از کاغذ مومی (کاغذی که لایه‌ی موم دارد و برای فر ساخته نشده) استفاده نکن. اگر دمای مجاز کاغذت از دمای فر کمتر است، بعد از {{ recipes.safety.parchment_pull_min.range.0 }} تا {{ recipes.safety.parchment_pull_min.range.1 }} دقیقه‌ی اول، وقتی کف پیتزا خودش را گرفت، کاغذ را از زیرش بیرون بکش. اگر از کاغذ استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Safety: روغن زیتون فرابکر از حدود {{ recipes.safety.evoo_smoke_c.range.0 }} تا {{ recipes.safety.evoo_smoke_c.range.1 }} درجه شروع به دود کردن می‌کند و این فر روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه است. سطح پخت داغ را روغن نزن. داخل این خمیر روغن نیست. برای حاشیه فقط یک لایه‌ی نازک بزن و روغن زیتون تصفیه‌شده یا سبک انتخاب کن، چون کمتر دود می‌کند.

    > Safety: دستکش فر بپوش. طبقه‌ی فر را فقط کمی بیرون بکش تا پیتزا را رویش بلغزانی، و هیچ‌وقت به سطح پخت دست نزن؛ تا مدت زیادی بعد از خاموش کردن فر هم داغ می‌ماند.
13. **بپز**
    {{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه با گرمای بالا و پایین بپز. {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخر گریل را روشن کن تا روی پیتزا و حاشیه رنگ بگیرد. کنار فر بمان و حواست به پیتزا باشد. پیتزا روی هم نباید بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه زیر گریل بماند. اگر از کاغذ روغنی استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.
    > Why: فر {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه از بالا گرمای کافی نمی‌دهد. فر واقعی ناپولیتن خیلی داغ‌تر است، پس گریل بخشی از آن گرما را جبران می‌کند.

    > Tip: پیتزا وقتی آماده است که حاشیه پف کرده و لکه‌های قهوه‌ای تا تیره دارد و کفش سفت شده است. پیش از اینکه لکه‌ها سیاه شوند، پیتزا را بیرون بیاور.
14. **پیتزا را دربیاور**
    اگر دوست داری، ریحان تازه و کمی روغن زیتون رویش بریز.

    > Why: خمیری که روی تخته یا کاغذ معطل بماند خیس می‌شود و می‌چسبد.

## تخمیر گرم، 2 ساعت {methods=warm_2h}

خمیر را درست می‌کنی و حدود دو ساعت بعد می‌پزی. مقدارها را از کارت «مواد لازم» همین صفحه بردار.

> Warning: این تخمیر دست‌کم {{ recipes.methods.warm_2h.min_pizzas }} پیتزا لازم دارد. برای یک پیتزا مخمر خشک کمتر از {{ recipes.yeast.min_weigh_g.value }} گرم می‌شود و ترازوی آشپزخانه نمی‌تواند آن را نشان دهد. این راهنما برای مخمر تازه هم همین قاعده را دارد. برای یک پیتزا تخمیر دیگری انتخاب کن.

1. **مخمر را آماده کن**
   1. آب خمیر را که ولرم است، با دمای حدود {{ recipes.methods.warm_2h.water_temp_c.value }} درجه، در یک کاسه‌ی بزرگ بریز.
   2. مقدار مخمر را که جدول نشان می‌دهد (ردیف «مخمر خشک» یا «مخمر تازه») وزن کن.
   3. مخمر تازه را اول خرد کن، بعد مخمر را در آب هم بزن. مخمر فوری خشک لازم نیست صبر کند.
   4. فعلاً نمک را داخل کاسه نریز: نمکی که مستقیم به مخمر برسد کارش را کند می‌کند.
   > Why: مخمر بین {{ recipes.styles.new_york.practice.yeast_works_c.range.0 }} تا {{ recipes.styles.new_york.practice.yeast_works_c.range.1 }} درجه تند کار می‌کند و از حدود {{ recipes.styles.new_york.practice.yeast_dies_c.value }} درجه شروع به مردن می‌کند، پس هیچ‌وقت آب داغ نریز. آب ولرم روی مچ دست فقط کمی گرم حس می‌شود، خنک‌تر از آب حمام.

   > Tip: مخمر فوری به فعال‌سازی نیاز ندارد، پس می‌توانی از این امتحان بگذری. اگر مخمرت کهنه است یا مطمئن نیستی زنده باشد، اول امتحانش کن: کمی از آن را در یک لیوان جدا، با آب ولرم هم بزن (یک ذره شکر کمک می‌کند کف زودتر پیدا شود؛ این شکر فقط برای امتحان است) و صبر کن تا روی آب کف بیاید. چند دقیقه طول می‌کشد. اگر کف نکرد، مخمر مرده است: مخمر نو بگیر.
2. **خمیر را مخلوط کن**
   1. حدود نصف آرد را بریز و هم بزن تا مخلوط صاف شود.
   2. بعد بقیه‌ی آرد را کم‌کم بریز و بعد از هر بار هم بزن.
   3. فقط آن‌قدر هم بزن که آرد خشکی نماند. کاسه‌ات آن‌قدر بزرگ باشد که موقع هم زدن بیرون نریزد.
   > Why: آردی که کم‌کم اضافه شود یکدست خیس می‌شود، پس گلوله‌ی خشک درست نمی‌شود و مخمر در خمیر پخش می‌شود.
3. **نمک را اضافه کن و ورز بده**
   نمک و شکر را روی خمیر بپاش و در آن کار کن. بعد {{ recipes.methods.warm_2h.knead_min.value }} دقیقه ورز بده. بخش «ورز دادن» در صفحه‌ی دستور نیویورکی طرز ورز دادن را توضیح می‌دهد. روغن اضافه نکن.
   > Why: وقت کم است، پس گلوتنی را که در استراحت طولانی خودبه‌خود ساخته می‌شد باید با ورز بسازی. نمک گلوتن را قوی‌تر می‌کند و کار مخمر را کند می‌کند.
4. **بگذار خمیر ور بیاید**
   1. خمیر را در ظرف دردار بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین).
   2. {{ recipes.methods.warm_2h.bulk_min.range.0 }} تا {{ recipes.methods.warm_2h.bulk_min.range.1 }} دقیقه در جای گرم نگه دار. دمای خوب {{ recipes.styles.new_york.practice.warm_place_c.range.0 }} تا {{ recipes.styles.new_york.practice.warm_place_c.range.1 }} درجه است.
   3. خمیر باید {{ recipes.styles.new_york.practice.rise_factor.range.0 }} تا {{ recipes.styles.new_york.practice.rise_factor.range.1 }} برابر شود. اگر جای گرم نداری، ور آمدن ممکن است تا {{ recipes.methods.warm_2h.bulk_slow_max_min.value }} دقیقه طول بکشد: به اندازه‌ی خمیر نگاه کن، نه به ساعت.
   > Why: هوای داخل خمیر باعث می‌شود حاشیه در فر پف کند.

   > Tip: ظرفی بردار که خمیر بتواند دو برابر شود و به درِ ظرف نخورد. سطح خمیر را بیرون ظرف با چسب کاغذی یا ماژیک علامت بزن تا ببینی چقدر بزرگ شده است.
5. **فر و سطح پخت را داغ کن**
   این کار را حدود نیمه‌ی زمان ور آمدن انجام بده تا وقتی چونه‌ها آماده شدند، سطح پخت داغ باشد.
   1. اگر خمیر داخل فر ور می‌آید، اول آن را بیرون بیاور.
   2. سطح پخت (سنگ پیتزا، فولاد پخت یا سینی چدنی) را در طبقه‌ی بالای فر بگذار، یعنی حدود یک‌سوم بالایی فر.
   3. فر را روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه، با گرمای بالا و پایین و **بدون فن** تنظیم کن.
   > Why: سطح پخت {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه لازم دارد تا کامل داغ شود. سطحی که کامل داغ نشده، کفی رنگ‌پریده و نرم می‌دهد. گرمای بالا و پایین گرما را مستقیم از زیر به سطح پخت می‌رساند. در حالت فن، المنت پایین اغلب خاموش است و هوای در حال حرکت روی پیتزا را زودتر از کفش خشک می‌کند و رنگ می‌اندازد. اگر فرت حالت پیتزا دارد (فن همراه با گرمای پایین)، می‌توانی امتحانش کنی و حواست به روی پیتزا باشد.
6. **خمیر را تقسیم و چونه کن**
   1. کل خمیر را روی ترازو بگذار. وزنش باید نزدیک «مجموع خمیر» در جدول مواد لازم باشد.
   2. این وزن را بر تعداد پیتزاها تقسیم کن. از خمیر تکه‌های هم‌وزن ببر.
   3. هر تکه را شکل بده: لبه‌ها را به وسط جمع کن، چونه را برگردان و با کف دست روی میز بچرخان تا سطحش کشیده و صاف شود.
   > Why: چونه‌های هم‌وزن یکنواخت می‌پزند و پیتزاهایی هم‌اندازه می‌دهند. ترازو از چشم دقیق‌تر است. سطح کشیده گاز را داخل نگه می‌دارد و چونه بعداً راحت‌تر باز می‌شود.
7. **چونه‌ها را استراحت بده**
   روی چونه‌ها را بپوشان و {{ recipes.methods.warm_2h.final_rest_min.range.0 }} تا {{ recipes.methods.warm_2h.final_rest_min.range.1 }} دقیقه بگذار. فر همچنان در حال گرم شدن است.
   > Why: گلوتن شل می‌شود. چونه‌ای که استراحت کرده راحت باز می‌شود و جمع نمی‌شود.
8. **چونه را باز کن**
   این کار را فقط وقتی فر داغ شد انجام بده. روی بقیه‌ی چونه‌ها پوشیده بماند.
   1. حدود {{ recipes.styles.new_york.practice.bench_flour_g.value }} گرم آرد (یا سمولینا) روی میز بپاش، چونه را رویش بگذار و با نوک انگشت‌ها از وسط به بیرون فشار بده. **به حاشیه‌ی {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متری دست نزن.**
   2. خمیر را با دو دست بکش و بچرخان تا به اندازه‌ای برسد که در صفحه‌ی اصلی انتخاب کرده‌ای (بالای همین صفحه نوشته شده).
   3. اگر خمیر جمع شد، بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند.
   > Why: حاشیه‌ی دست‌نخورده هوایش را نگه می‌دارد، پس در فر پف می‌کند. حاشیه‌ی بلند و نرم نشانه‌ی پیتزای ناپولیتن است.

   > Warning: از وردنه استفاده نکن. وردنه هوای خمیر را بیرون می‌دهد و حاشیه پف نمی‌کند.
9. **روی پیتزا را بچین**
   ساده بچین.
   1. یک لایه‌ی نازک سس پخش کن و حاشیه را (حدود {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر) خالی بگذار.
   2. پنیر و هر چیز دیگری که دوست داری رویش بریز.
   3. بعد حاشیه را با کمی روغن زیتون چرب کن. روی پیتزا زیاد مواد نریز. سریع کار کن، چون خمیری که روی تخته یا کاغذ معطل بماند می‌چسبد.
   > Why: مواد رویی سبک اجازه می‌دهند بخار بیرون برود، پس وسط پیتزا به‌جای خیس ماندن سفت می‌شود. مواد زیاد پیتزا را سنگین می‌کند و لغزاندنش سخت می‌شود. مواد آبدار را اول با دستمال خشک کن و پنیر رنده‌شده‌ی خشک بریز.
10. **پیتزا را داخل فر بلغزان**
    آن را از روی تخته یا کفگیر پیتزا (پاروی تخت مخصوص پیتزا) روی سطح پخت ببر. روی تخته کمی سمولینا یا آرد بپاش، یا اگر ترجیح می‌دهی از کاغذ روغنی استفاده کن (یادداشت ایمنی پایین را ببین).
    > Why: هر بار که در فر را باز می‌کنی، گرما از دست می‌رود. سریع باش.

    > Safety: استفاده از کاغذ روغنی (کاغذ مخصوص فر) انتخاب خودت است. بدون کاغذ: خمیر را روی تخته یا کفگیر پیتزایی که کمی سمولینا یا آرد رویش پاشیده‌ای باز کن، بعد روی سطح داغ بلغزان. با کاغذ: حداکثر دمای چاپ‌شده روی بسته را ببین. دمای مجاز خیلی از کاغذها {{ recipes.safety.parchment_max_c.value }} درجه است که از دمای این فر کمتر است. کاغذ را از المنت‌ها و دیواره‌های فر دور نگه دار و لبه‌های اضافی‌اش را قیچی کن. از کاغذ مومی (کاغذی که لایه‌ی موم دارد و برای فر ساخته نشده) استفاده نکن. اگر دمای مجاز کاغذت از دمای فر کمتر است، بعد از {{ recipes.safety.parchment_pull_min.range.0 }} تا {{ recipes.safety.parchment_pull_min.range.1 }} دقیقه‌ی اول، وقتی کف پیتزا خودش را گرفت، کاغذ را از زیرش بیرون بکش. اگر از کاغذ استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

## عیب‌یابی

- **حاشیه پف نکرد.** موقع باز کردن روی حاشیه فشار آورده‌ای، یا خمیر به اندازه‌ی کافی ور نیامده بود. خمیر را از وسط باز کن و به حاشیه دست نزن.
- **کف رنگ نگرفت یا نرم ماند.** سطح پخت به اندازه‌ی کافی داغ نبوده. آن را {{ recipes.oven.preheat_min.range.1 }} دقیقه داغ کن.
- **روی پیتزا کم‌رنگ ماند ولی کفش رنگ گرفت.** سطح پخت را طبقه‌ی بالاتر بگذار و {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخر گریل را روشن کن.
- **حاشیه یا روی پیتزا زیر گریل سوخت.** گریل را مدت کوتاه‌تری روشن بگذار. روی هم هیچ‌وقت بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه روشنش نکن.
- **خمیر جمع می‌شود.** گلوتن سفت است یا خمیر سرد است. بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند.
- **خمیر پاره می‌شود.** یا سرد است یا گلوتنش ضعیف است. بگذار استراحت کند، یا سوراخ را با یک تکه‌ی کوچک خمیر وصله کن.
- **بوی تند الکل یا ترشی می‌دهد.** خمیر زیادی ور آمده. دفعه‌ی بعد مخمر کمتر بریز یا زمان را کوتاه‌تر کن. در اتاق گرم، زمان ور آمدن را کوتاه کن.
- **خمیر خیلی چسبناک یا خیلی سفت است.** قسمت‌های «خمیر چسبناک است» و «خمیر خشک است» را در بخش «ورز دادن» صفحه‌ی دستور نیویورکی ببین.

## قوانین اصلی چه می‌گویند

پیتزای ناپولیتن اصل قوانینی دارد که «انجمن پیتزای اصیل ناپلی» آن‌ها را تعیین کرده است؛ انجمنی در ناپل که از پیتزای اصل محافظت می‌کند. این راهنما از واقعیت‌های زیر استفاده می‌کند. این‌ها فقط برای اطلاع‌اند و لازم نیست پیتزای خانگی تو از آن‌ها پیروی کند.

- **تخمیر:** روی هم {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.1 }} ساعت. قوانین دمایی تعیین نمی‌کنند. در ناپل خمیر در دمای اتاق می‌ماند.
- **چونه و اندازه:** چونه‌ی {{ recipes.styles.neapolitan.ball_g.range.0 }} تا {{ recipes.styles.neapolitan.ball_g.range.1 }} گرمی و پیتزایی با قطر {{ recipes.styles.neapolitan.practice.avpn_diameter_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_diameter_cm.range.1 }} سانتی‌متر. در این راهنما می‌توانی قطر {{ recipes.sizes.0.diameter }}، {{ recipes.sizes.1.diameter }} یا {{ recipes.sizes.2.diameter }} سانتی‌متر را انتخاب کنی و کارت «مواد لازم» وزن چونه را برای همان اندازه نشان می‌دهد. چونه‌ی بزرگ‌ترین اندازه کمی از حداکثر قوانین اصلی سنگین‌تر است.
- **حاشیه:** {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر.
- **فر:** {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.1 }} درجه و پخت در {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.1 }} ثانیه. فر خانگی به این دما نمی‌رسد.
- **مواد:** آرد، آب، نمک و مخمر. مشخصات رسمی اتحادیه‌ی اروپا برای پیتزای ناپلی برای خمیر فقط همین‌ها را نام می‌برد؛ روغن زیتون فقط روی پیتزا می‌رود. این دستور خانگی برای رنگ‌گیری کمی شکر اضافه می‌کند.
