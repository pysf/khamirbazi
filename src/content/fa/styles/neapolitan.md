## پیتزای آماده

پیتزای ناپولیتن وسطش نازک و نرم است و حاشیه‌ای بلند، نرم و پف‌کرده دارد. همه‌ی دماهای این سایت به درجه‌ی سانتی‌گراد است. نتیجه این‌طور است:

- **وسط:** نازک و نرم. خم می‌شود. مثل کراکر ترد نیست.
- **حاشیه (لبه‌ی پیتزا):** بلند، پرهوا و لطیف، با چند لکه‌ی قهوه‌ای تا تیره که گرما رویش می‌اندازد.
- **در خانه:** فر واقعی ناپولیتن روی {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.1 }} درجه کار می‌کند و پیتزا را در {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.1 }} ثانیه می‌پزد. فر تو تا {{ recipes.oven.max_c.value }} درجه گرم می‌شود، پس پخت {{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه طول می‌کشد. نتیجه پیتزای **به سبک ناپولیتن** است، نه خود اصلش. حاشیه کمی سفت‌تر می‌شود و رنگش کمتر تیره. ولی باز هم پیتزای خیلی خوبی است.

دستور اصلی بیشتر به طعم و بافت توجه دارد تا عددهای دقیق. همه‌ی مقدارها و زمان‌های اینجا نقطه‌ی شروع‌اند. یک بار بپز، خمیر و پوسته را نگاه کن و دفعه‌ی بعد هر چه لازم است تغییر بده.

## انتخاب روش

در ناپل خمیر معمولاً {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.1 }} ساعت در دمای اتاق و با مخمر خیلی کم تخمیر می‌شود. تخمیر یعنی مخمر قند را می‌خورد و گاز و طعم می‌سازد. سه روش داری. روش را در صفحه‌ی اصلی انتخاب می‌کنی و کارت «مواد لازم» در همین صفحه مقدارهای همان روش را نشان می‌دهد. برای امتحان روش دیگر، بالای صفحه «تغییر» را بزن.

**روش دمای اتاق، {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت: نزدیک‌ترین به ناپل.** خمیر در دمای اتاق (حدود {{ recipes.oven.room_c.value }} درجه) ور می‌آید؛ اول یک‌تکه و بعد به شکل چونه.

- **مزیت‌ها:** در ناپل همین‌طور درستش می‌کنند. ور آمدن آرام طعم عمیقی می‌دهد.
- **عیب‌ها:** باید روزت را برنامه‌ریزی کنی و زمان‌بندی به دمای اتاقت بستگی دارد. اتاق گرم‌تر یعنی ور آمدن سریع‌تر. مقدار مخمر این روش نامطمئن‌ترین مقدار این راهنماست.

**روش یخچال، {{ recipes.methods.cold_24h.fridge_h.value }} ساعت: برنامه‌ریزی‌اش از همه راحت‌تر است.** خمیر در یخچال (حدود {{ recipes.oven.fridge_c.range.0 }} تا {{ recipes.oven.fridge_c.range.1 }} درجه) استراحت می‌کند. مخمر آنجا آرام کار می‌کند.

- **مزیت‌ها:** طعم عمیق. اگر برنامه‌ات عوض شد، خمیر در یخچال می‌ماند. روز پخت کار زیادی نداری.
- **عیب‌ها:** در یخچال جا لازم داری و مقدار مخمر باید دقیق باشد. برای همین این روش از «محلول مخمر» استفاده می‌کند.

**روش 2 ساعته: وقتی عجله داری.** خمیر را درست می‌کنی و حدود دو ساعت بعد می‌پزی.

- **مزیت‌ها:** همان روز آماده است.
- **عیب‌ها:** طعمش ساده‌تر و بیشتر شبیه نان معمولی است. در بین این سه روش، از همه از اصلش دورتر است.
- **دست‌کم {{ recipes.methods.warm_2h.min_pizzas }} پیتزا لازم دارد.** برای یک پیتزا مخمر آن‌قدر کم می‌شود که ترازوی آشپزخانه نشانش نمی‌دهد.

**خلاصه:** اگر وقت داری، برای نزدیک‌ترین نتیجه روش دمای اتاق را انتخاب کن، یا برای راحت‌ترین برنامه روش یخچال را. اگر می‌خواهی همین امروز بخوری، روش 2 ساعته هم پیتزای خوشمزه‌ای می‌دهد.

## آرد و مخمر

**آرد.** همان آرد پیتزایی را بگیر که برای پیتزای نیویورکی می‌گیری (که اغلب روی بسته‌اش «تیپو 00» نوشته شده). صفحه‌ی دستور نیویورکی در بخش «آرد و مخمر» توضیح می‌دهد پروتئین روی بسته را چطور بخوانی.

**مخمر.** کارت «مواد لازم» همان مخمری را نشان می‌دهد که در صفحه‌ی اصلی انتخاب کرده‌ای (خشک یا تازه). صفحه‌ی دستور نیویورکی در بخش «آرد و مخمر» هر دو نوع را توضیح داده است. روش دمای اتاق و روش یخچال از محلول مخمر استفاده می‌کنند، چون مقدار مخمر برای ترازوی آشپزخانه خیلی کم است. مرحله‌ی اول همین روش‌ها طرز کارش را توضیح می‌دهد.

- **شکر:** خمیر اصلی شکر ندارد. این دستور خانگی کمی شکر دارد ({{ recipes.styles.neapolitan.dough.sugar.value }}% وزن آرد؛ کارت «مواد لازم» مقدارش را به گرم نشان می‌دهد)، چون فر {{ recipes.oven.max_c.value }} درجه پیتزا را کمتر از فر واقعی ناپولیتن رنگ می‌اندازد. می‌توانی شکر را نریزی.
- **روغن:** هیچ. داخل این خمیر روغن نیست.

> Warning: مقدار مخمر نقطه‌ی شروع است، نه قانون ثابت. منبع‌ها برای یک برنامه‌ی یکسان تا {{ recipes.yeast.source_spread_x.value }} برابر با هم فرق دارند. مقدار درست به دمای اتاق یا یخچال و مخمر خودت بستگی دارد. یک بار بپز، خمیر و پوسته را نگاه کن و دفعه‌ی بعد مقدار را تغییر بده.

## روش دمای اتاق {methods=room_8_12h}

خمیر را صبح درست می‌کنی و عصر می‌پزی، یا برعکس. خمیر روی هم {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت در دمای اتاق ور می‌آید. مقدارها را از کارت «مواد لازم» همین صفحه بردار.

> Warning: دمای اتاق سرعت ور آمدن را خیلی تغییر می‌دهد. این برنامه برای اتاقی با دمای حدود {{ recipes.oven.room_c.value }} درجه است. اگر اتاق گرم‌تر از {{ recipes.styles.new_york.practice.hot_room_c.value }} درجه است، هر دو مرحله‌ی ور آمدن را کوتاه‌تر کن و حواست به خمیر باشد.

1. **محلول مخمر را درست کن و خمیر را مخلوط کن** یک بسته‌ی {{ recipes.yeast.solution.dry.yeast_g.value }} گرمی مخمر خشک را در {{ recipes.yeast.solution.dry.water_g.value }} گرم آب ولرم هم بزن تا حل شود. اگر مخمر تازه داری، نصف یک مکعب {{ recipes.yeast.solution.fresh.cube_g.value }} گرمی ({{ recipes.yeast.solution.fresh.yeast_g.value }} گرم) را در {{ recipes.yeast.solution.fresh.water_g.value }} گرم آب حل کن. بعد آب خنک (حدود {{ recipes.methods.room_8_12h.water_temp_c.value }} درجه) را در کاسه بریز. به اندازه‌ای که کارت «مواد لازم» نشان می‌دهد محلول مخمر اضافه کن و بعد آرد را بریز. فقط آن‌قدر هم بزن که آرد خشکی نماند.

    > Why: مقدار مخمر آن‌قدر کم است که با ترازوی آشپزخانه وزن نمی‌شود، پس به‌جایش بخشی از محلول را وزن می‌کنی. کارت «مواد لازم» وزن محلول را از قبل از آب کم کرده است.
2. **روی خمیر را بپوشان و بگذار {{ recipes.methods.room_8_12h.autolyse_min.range.0 }} تا {{ recipes.methods.room_8_12h.autolyse_min.range.1 }} دقیقه استراحت کند** به این استراحت «اتولیز» می‌گویند.

    > Why: آب و آنزیم‌های آرد خودبه‌خود ساختن گلوتن را شروع می‌کنند، پس ورز کمتری لازم است.
3. **نمک و شکر را اضافه کن، بعد {{ recipes.methods.room_8_12h.knead_min.range.0 }} تا {{ recipes.methods.room_8_12h.knead_min.range.1 }} دقیقه ورز بده** آن‌ها را در خمیر کار کن تا یکدست شود. بخش «ورز دادن» در صفحه‌ی دستور نیویورکی طرز ورز دادن را توضیح می‌دهد. روغن اضافه نکن.

    > Why: نمک گلوتن را قوی‌تر می‌کند و کار مخمر را کند می‌کند. گلوتن همان شبکه‌ی کشسانی است که گاز مخمر را نگه می‌دارد.
4. **بگذار خمیر یک‌تکه {{ recipes.methods.room_8_12h.bulk_min.value }} دقیقه ور بیاید** آن را در ظرف دردار بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین) و در دمای اتاق نگه دار.

    > Why: مخمر گاز می‌سازد و گاز خمیر را بزرگ و پف‌دار می‌کند. ور آمدن آرام در دمای اتاق طعم می‌سازد.
5. **خمیر را به چونه‌های هم‌وزن تقسیم کن** کل خمیر را روی ترازو بگذار. وزنش باید نزدیک «مجموع خمیر» در کارت «مواد لازم» باشد. این وزن را بر تعداد پیتزاها تقسیم کن. از خمیر تکه‌هایی به همین وزن ببر و هر تکه را شکل بده: لبه‌ها را به وسط جمع کن، چونه را برگردان و با کف دست روی میز بچرخان تا سطحش کشیده و صاف شود. هر چونه را در یک ظرف دردار جدا بگذار.

    > Why: چونه‌های هم‌وزن یکنواخت می‌پزند و پیتزاهایی هم‌اندازه می‌دهند. ترازو از چشم دقیق‌تر است. سطح کشیده گاز را داخل نگه می‌دارد و چونه بعداً راحت‌تر باز می‌شود.
6. **روی چونه‌ها را بپوشان و بگذار {{ recipes.methods.room_8_12h.final_rest_min.value }} دقیقه استراحت کنند** کل ور آمدن، از مخلوط کردن تا پخت، {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت طول می‌کشد.

    > Why: خمیر در چونه‌ها آرام به ور آمدن ادامه می‌دهد و گلوتن شل می‌شود. چونه‌ای که استراحت کرده راحت باز می‌شود و جمع نمی‌شود.
7. **فر و سطح پخت را داغ کن** این کار را {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه پیش از پخت انجام بده، وقتی چونه‌ها هنوز در حال استراحت‌اند. سطح پخت (سنگ پیتزا، فولاد پخت یا سینی چدنی) را در طبقه‌ی بالای فر بگذار، یعنی حدود یک‌سوم بالایی فر. فر را روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه، با گرمای بالا و پایین و **بدون فن** تنظیم کن.

    > Why: سطحی که کامل داغ نشده، کفی رنگ‌پریده و نرم می‌دهد. فن خمیر را خشک می‌کند و روی پیتزا را پیش از آماده شدن کف می‌سوزاند.
8. **یک چونه را با نوک انگشت‌ها باز کن و گرد کن** این کار را فقط وقتی فر داغ شد انجام بده. روی بقیه‌ی چونه‌ها پوشیده بماند. حدود {{ recipes.styles.new_york.practice.bench_flour_g.value }} گرم آرد روی میز بپاش، چونه را رویش بگذار و از وسط به بیرون فشار بده. **به حاشیه‌ی {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متری دست نزن.** خمیر را با دو دست بکش و بچرخان تا قطرش به {{ recipes.styles.neapolitan.practice.shape_diameter_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.shape_diameter_cm.range.1 }} سانتی‌متر برسد. اگر خمیر جمع شد، بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند.

    > Why: حاشیه‌ی دست‌نخورده هوایش را نگه می‌دارد، پس در فر پف می‌کند. حاشیه‌ی بلند و نرم نشانه‌ی پیتزای ناپولیتن است.

    > Warning: از وردنه استفاده نکن. وردنه هوای خمیر را بیرون می‌دهد و حاشیه پف نمی‌کند.
9. **روی پیتزا را بچین** ساده بچین. یک لایه‌ی نازک سس پخش کن و حاشیه را (حدود {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر) خالی بگذار. پنیر و هر چیز دیگری که دوست داری رویش بریز، بعد حاشیه را با کمی روغن زیتون چرب کن. سریع کار کن، چون خمیری که روی تخته یا کاغذ معطل بماند می‌چسبد.

    > Why: مواد رویی سبک اجازه می‌دهند بخار بیرون برود، پس وسط پیتزا به‌جای خیس ماندن سفت می‌شود. مواد آبدار را اول با دستمال خشک کن و پنیر رنده‌شده‌ی خشک بریز.

10. **پیتزا را سریع روی سطح داغ بلغزان** آن را از روی تخته یا کفگیر پیتزا (پاروی تخت مخصوص پیتزا) روی سطح پخت ببر. روی تخته کمی سمولینا یا آرد بپاش، یا اگر ترجیح می‌دهی از کاغذ روغنی استفاده کن (یادداشت ایمنی پایین را ببین).

    > Why: هر بار که در فر را باز می‌کنی، گرما از دست می‌رود. سریع باش.

    > Safety: استفاده از کاغذ روغنی انتخاب خودت است. بدون کاغذ: خمیر را روی تخته یا کفگیر پیتزایی که کمی سمولینا یا آرد رویش پاشیده‌ای باز کن، بعد روی سطح داغ بلغزان. با کاغذ: حداکثر دمای چاپ‌شده روی بسته را ببین. دمای مجاز خیلی از کاغذها {{ recipes.safety.parchment_max_c.value }} درجه است که از دمای این فر کمتر است. کاغذ را از المنت‌ها و دیواره‌های فر دور نگه دار و لبه‌های اضافی‌اش را قیچی کن. اگر از کاغذ استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Safety: روغن زیتون فرابکر از حدود {{ recipes.safety.evoo_smoke_c.range.0 }} تا {{ recipes.safety.evoo_smoke_c.range.1 }} درجه شروع به دود کردن می‌کند و این فر روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه است. سطح پخت داغ را روغن نزن. داخل این خمیر روغن نیست. برای حاشیه فقط یک لایه‌ی نازک بزن و روغن زیتون تصفیه‌شده یا سبک انتخاب کن، چون کمتر دود می‌کند.
11. **{{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه بپز و آخر کار گریل را روشن کن** با گرمای بالا و پایین بپز. {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخر گریل را روشن کن تا روی پیتزا و حاشیه رنگ بگیرد. کنار فر بمان و حواست به پیتزا باشد. پیتزا روی هم نباید بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه زیر گریل بماند. اگر از کاغذ روغنی استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Why: فر {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه از بالا گرمای کافی نمی‌دهد. فر واقعی ناپولیتن خیلی داغ‌تر است، پس گریل بخشی از آن گرما را جبران می‌کند.

    > Tip: پیتزا وقتی آماده است که حاشیه پف کرده و لکه‌های قهوه‌ای تا تیره دارد و کفش سفت شده است. پیش از اینکه لکه‌ها سیاه شوند، پیتزا را بیرون بیاور.
12. **پیتزا را از فر دربیاور** اگر دوست داری، ریحان تازه و کمی روغن زیتون رویش بریز.
13. **برای پیتزای دوم صبر کن** روی چونه‌اش را بپوشان تا پیتزای اول بیرون بیاید و سطح پخت دوباره داغ شود. این کار حدود {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.0 }} تا {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.1 }} دقیقه طول می‌کشد. فقط بعد از آن چونه را باز کن.

    > Why: خمیری که روی تخته یا کاغذ معطل بماند خیس می‌شود و می‌چسبد.

## روش یخچال {methods=cold_24h}

خمیر را یک روز پیش از پخت درست می‌کنی. مقدارها را از کارت «مواد لازم» همین صفحه بردار. مرحله‌های 1 تا 6 مال روز اول است و بقیه‌ی مرحله‌ها مال روز پخت.

> Tip: محلول مخمر را درست پیش از استفاده آماده کن و باقی‌مانده‌اش را دور بریز. هیچ منبعی نمی‌گوید محلول مخمر تا کی سالم می‌ماند، برای همین این راهنما مدت نگهداری برایش نمی‌دهد.

1. **محلول مخمر را درست کن و خمیر را مخلوط کن** یک بسته‌ی {{ recipes.yeast.solution.dry.yeast_g.value }} گرمی مخمر خشک را در {{ recipes.yeast.solution.dry.water_g.value }} گرم آب ولرم هم بزن تا حل شود. اگر مخمر تازه داری، نصف یک مکعب {{ recipes.yeast.solution.fresh.cube_g.value }} گرمی ({{ recipes.yeast.solution.fresh.yeast_g.value }} گرم) را در {{ recipes.yeast.solution.fresh.water_g.value }} گرم آب حل کن. بعد آب سرد (حدود {{ recipes.methods.cold_24h.water_temp_c.value }} درجه) را در کاسه بریز. به اندازه‌ای که کارت «مواد لازم» نشان می‌دهد محلول مخمر اضافه کن و بعد آرد را بریز. فقط آن‌قدر هم بزن که آرد خشکی نماند.

    > Why: مقدار مخمر آن‌قدر کم است که با ترازوی آشپزخانه وزن نمی‌شود، پس به‌جایش بخشی از محلول را وزن می‌کنی. کارت «مواد لازم» وزن محلول را از قبل از آب سرد کم کرده است.
2. **روی خمیر را بپوشان و بگذار {{ recipes.methods.cold_24h.autolyse_min.range.0 }} تا {{ recipes.methods.cold_24h.autolyse_min.range.1 }} دقیقه استراحت کند** به این استراحت «اتولیز» می‌گویند.

    > Why: آب و آنزیم‌های آرد خودبه‌خود ساختن گلوتن را شروع می‌کنند، پس ورز کمتری لازم است.
3. **نمک و شکر را اضافه کن، بعد {{ recipes.methods.cold_24h.knead_min.range.0 }} تا {{ recipes.methods.cold_24h.knead_min.range.1 }} دقیقه ورز بده** آن‌ها را در خمیر کار کن تا یکدست شود. بخش «ورز دادن» در صفحه‌ی دستور نیویورکی طرز ورز دادن را توضیح می‌دهد، و اینکه چطور به‌جایش از کشیدن و تا کردن استفاده کنی. روغن اضافه نکن.

    > Why: نمک گلوتن را قوی‌تر می‌کند و کار مخمر را کند می‌کند.
4. **بگذار در دمای اتاق ور بیاید** (حدود {{ recipes.oven.room_c.value }} درجه)، {{ recipes.methods.cold_24h.room_rest_min.range.0 }} تا {{ recipes.methods.cold_24h.room_rest_min.range.1 }} دقیقه با روی پوشیده، تا خمیر حدود {{ recipes.styles.new_york.practice.cold_rise_pct.value }}% بزرگ‌تر شود.

    > Why: مخمر پیش از رفتن به سرما یک شروع گرم و کوتاه لازم دارد.
5. **خمیر را به چونه‌های هم‌وزن تقسیم کن** کل خمیر را روی ترازو بگذار. وزنش باید نزدیک «مجموع خمیر» در کارت «مواد لازم» باشد. این وزن را بر تعداد پیتزاها تقسیم کن. از خمیر تکه‌هایی به همین وزن ببر و هر تکه را شکل بده: لبه‌ها را به وسط جمع کن، چونه را برگردان و با کف دست روی میز بچرخان تا سطحش کشیده و صاف شود. هر چونه را در یک ظرف دردار جدا بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین).

    > Why: چونه‌های هم‌وزن یکنواخت می‌پزند و پیتزاهایی هم‌اندازه می‌دهند. ترازو از چشم دقیق‌تر است. سطح کشیده گاز را داخل نگه می‌دارد و چونه بعداً راحت‌تر باز می‌شود.
6. **ظرف‌ها را {{ recipes.methods.cold_24h.fridge_h.value }} ساعت در یخچال بگذار**

    > Why: در یخچال مخمر آرام کار می‌کند و آنزیم‌ها فرصت دارند طعم بسازند. نتیجه طعم عمیق‌تر و رنگ‌گیری بهتر است.
7. **روز پخت، خمیر را {{ recipes.methods.cold_24h.take_out_lead_min.range.0 }} تا {{ recipes.methods.cold_24h.take_out_lead_min.range.1 }} دقیقه پیش از باز کردن از یخچال بیرون بیاور** در ظرف را باز نکن.

    > Why: خمیر سرد کش نمی‌آید و پاره می‌شود. این رایج‌ترین اشتباه در تخمیر سرد است.
8. **فر و سطح پخت را داغ کن** این کار را {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه پیش از پخت انجام بده، همان وقتی که خمیر دارد از سرما درمی‌آید. سطح پخت (سنگ پیتزا، فولاد پخت یا سینی چدنی) را در طبقه‌ی بالای فر بگذار، یعنی حدود یک‌سوم بالایی فر. فر را روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه، با گرمای بالا و پایین و **بدون فن** تنظیم کن.

    > Why: سطحی که کامل داغ نشده، کفی رنگ‌پریده و نرم می‌دهد. فن خمیر را خشک می‌کند و روی پیتزا را پیش از آماده شدن کف می‌سوزاند.
9. **یک چونه را با نوک انگشت‌ها باز کن و گرد کن** این کار را فقط وقتی فر داغ شد انجام بده. روی بقیه‌ی چونه‌ها پوشیده بماند. حدود {{ recipes.styles.new_york.practice.bench_flour_g.value }} گرم آرد روی میز بپاش، چونه را رویش بگذار و از وسط به بیرون فشار بده. **به حاشیه‌ی {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متری دست نزن.** خمیر را با دو دست بکش و بچرخان تا قطرش به {{ recipes.styles.neapolitan.practice.shape_diameter_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.shape_diameter_cm.range.1 }} سانتی‌متر برسد. اگر خمیر جمع شد، بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند.

    > Why: حاشیه‌ی دست‌نخورده هوایش را نگه می‌دارد، پس در فر پف می‌کند. حاشیه‌ی بلند و نرم نشانه‌ی پیتزای ناپولیتن است.

    > Warning: از وردنه استفاده نکن. وردنه هوای خمیر را بیرون می‌دهد و حاشیه پف نمی‌کند.
10. **روی پیتزا را بچین** ساده بچین. یک لایه‌ی نازک سس پخش کن و حاشیه را (حدود {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر) خالی بگذار. پنیر و هر چیز دیگری که دوست داری رویش بریز، بعد حاشیه را با کمی روغن زیتون چرب کن. سریع کار کن، چون خمیری که روی تخته یا کاغذ معطل بماند می‌چسبد.

    > Why: مواد رویی سبک اجازه می‌دهند بخار بیرون برود، پس وسط پیتزا به‌جای خیس ماندن سفت می‌شود. مواد آبدار را اول با دستمال خشک کن و پنیر رنده‌شده‌ی خشک بریز.

11. **پیتزا را سریع روی سطح داغ بلغزان** آن را از روی تخته یا کفگیر پیتزا (پاروی تخت مخصوص پیتزا) روی سطح پخت ببر. روی تخته کمی سمولینا یا آرد بپاش، یا اگر ترجیح می‌دهی از کاغذ روغنی استفاده کن (یادداشت ایمنی پایین را ببین).

    > Why: هر بار که در فر را باز می‌کنی، گرما از دست می‌رود. سریع باش.

    > Safety: استفاده از کاغذ روغنی انتخاب خودت است. بدون کاغذ: خمیر را روی تخته یا کفگیر پیتزایی که کمی سمولینا یا آرد رویش پاشیده‌ای باز کن، بعد روی سطح داغ بلغزان. با کاغذ: حداکثر دمای چاپ‌شده روی بسته را ببین. دمای مجاز خیلی از کاغذها {{ recipes.safety.parchment_max_c.value }} درجه است که از دمای این فر کمتر است. کاغذ را از المنت‌ها و دیواره‌های فر دور نگه دار و لبه‌های اضافی‌اش را قیچی کن. اگر از کاغذ استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Safety: روغن زیتون فرابکر از حدود {{ recipes.safety.evoo_smoke_c.range.0 }} تا {{ recipes.safety.evoo_smoke_c.range.1 }} درجه شروع به دود کردن می‌کند و این فر روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه است. سطح پخت داغ را روغن نزن. داخل این خمیر روغن نیست. برای حاشیه فقط یک لایه‌ی نازک بزن و روغن زیتون تصفیه‌شده یا سبک انتخاب کن، چون کمتر دود می‌کند.
12. **{{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه بپز و آخر کار گریل را روشن کن** با گرمای بالا و پایین بپز. {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخر گریل را روشن کن تا روی پیتزا و حاشیه رنگ بگیرد. کنار فر بمان و حواست به پیتزا باشد. پیتزا روی هم نباید بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه زیر گریل بماند. اگر از کاغذ روغنی استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Why: فر {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه از بالا گرمای کافی نمی‌دهد. فر واقعی ناپولیتن خیلی داغ‌تر است، پس گریل بخشی از آن گرما را جبران می‌کند.

    > Tip: پیتزا وقتی آماده است که حاشیه پف کرده و لکه‌های قهوه‌ای تا تیره دارد و کفش سفت شده است. پیش از اینکه لکه‌ها سیاه شوند، پیتزا را بیرون بیاور.
13. **پیتزا را از فر دربیاور** اگر دوست داری، ریحان تازه و کمی روغن زیتون رویش بریز.
14. **برای پیتزای دوم صبر کن** روی چونه‌اش را بپوشان تا پیتزای اول بیرون بیاید و سطح پخت دوباره داغ شود. این کار حدود {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.0 }} تا {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.1 }} دقیقه طول می‌کشد. فقط بعد از آن چونه را باز کن.

    > Why: خمیری که روی تخته یا کاغذ معطل بماند خیس می‌شود و می‌چسبد.

## روش 2 ساعته {methods=warm_2h}

خمیر را درست می‌کنی و حدود دو ساعت بعد می‌پزی. مقدارها را از کارت «مواد لازم» همین صفحه بردار.

> Warning: این روش دست‌کم {{ recipes.methods.warm_2h.min_pizzas }} پیتزا لازم دارد. برای یک پیتزا مخمر کمتر از {{ recipes.yeast.min_weigh_g.value }} گرم می‌شود و ترازوی آشپزخانه نمی‌تواند آن را نشان دهد. برای یک پیتزا از روش دیگری استفاده کن.

1. **مخمر را در آب ولرم هم بزن** آبی با دمای حدود {{ recipes.methods.warm_2h.water_temp_c.value }} درجه بردار. برای مخمر خشک لازم نیست منتظر بمانی.

    > Why: مخمر بین {{ recipes.styles.new_york.practice.yeast_works_c.range.0 }} تا {{ recipes.styles.new_york.practice.yeast_works_c.range.1 }} درجه تند کار می‌کند و بالای {{ recipes.styles.new_york.practice.yeast_dies_c.value }} درجه می‌میرد. آب ولرم مثل آب گرم حمام است، نه داغ.
2. **آرد، نمک و شکر را اضافه کن و {{ recipes.methods.warm_2h.knead_min.value }} دقیقه ورز بده** پیش از ورز، آن‌قدر هم بزن که آرد خشکی نماند. بخش «ورز دادن» در صفحه‌ی دستور نیویورکی طرز ورز دادن را توضیح می‌دهد. روغن اضافه نکن.

    > Why: وقت کم است، پس گلوتنی را که در استراحت طولانی خودبه‌خود ساخته می‌شد باید با ورز بسازی.
3. **بگذار خمیر ور بیاید** آن را در ظرف دردار بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین). {{ recipes.methods.warm_2h.bulk_min.range.0 }} تا {{ recipes.methods.warm_2h.bulk_min.range.1 }} دقیقه در جای گرم بماند. دمای خوب {{ recipes.styles.new_york.practice.warm_place_c.range.0 }} تا {{ recipes.styles.new_york.practice.warm_place_c.range.1 }} درجه است. خمیر باید {{ recipes.styles.new_york.practice.rise_factor.range.0 }} تا {{ recipes.styles.new_york.practice.rise_factor.range.1 }} برابر شود.

    > Why: هوای داخل خمیر باعث می‌شود حاشیه در فر پف کند.

    > Why: چونه‌های هم‌وزن یکنواخت می‌پزند و پیتزاهایی هم‌اندازه می‌دهند. ترازو از چشم دقیق‌تر است. سطح کشیده گاز را داخل نگه می‌دارد و چونه بعداً راحت‌تر باز می‌شود.
5. **روی چونه‌ها را بپوشان و بگذار {{ recipes.methods.warm_2h.final_rest_min.range.0 }} تا {{ recipes.methods.warm_2h.final_rest_min.range.1 }} دقیقه استراحت کنند** همین حالا فر را هم داغ کن (مرحله‌ی بعد).

    > Why: گلوتن شل می‌شود. چونه‌ای که استراحت کرده راحت باز می‌شود و جمع نمی‌شود.
6. **فر و سطح پخت را داغ کن** این کار را {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه پیش از پخت انجام بده، در همان مدتی که چونه‌ها استراحت می‌کنند. سطح پخت (سنگ پیتزا، فولاد پخت یا سینی چدنی) را در طبقه‌ی بالای فر بگذار، یعنی حدود یک‌سوم بالایی فر. فر را روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه، با گرمای بالا و پایین و **بدون فن** تنظیم کن.

7. **یک چونه را با نوک انگشت‌ها باز کن و گرد کن** این کار را فقط وقتی فر داغ شد انجام بده. روی بقیه‌ی چونه‌ها پوشیده بماند. حدود {{ recipes.styles.new_york.practice.bench_flour_g.value }} گرم آرد روی میز بپاش، چونه را رویش بگذار و از وسط به بیرون فشار بده. **به حاشیه‌ی {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متری دست نزن.** خمیر را با دو دست بکش و بچرخان تا قطرش به {{ recipes.styles.neapolitan.practice.shape_diameter_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.shape_diameter_cm.range.1 }} سانتی‌متر برسد. اگر خمیر جمع شد، بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند.

    > Why: حاشیه‌ی دست‌نخورده هوایش را نگه می‌دارد، پس در فر پف می‌کند. حاشیه‌ی بلند و نرم نشانه‌ی پیتزای ناپولیتن است.

    > Warning: از وردنه استفاده نکن. وردنه هوای خمیر را بیرون می‌دهد و حاشیه پف نمی‌کند.
8. **روی پیتزا را بچین** ساده بچین. یک لایه‌ی نازک سس پخش کن و حاشیه را (حدود {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر) خالی بگذار. پنیر و هر چیز دیگری که دوست داری رویش بریز، بعد حاشیه را با کمی روغن زیتون چرب کن. سریع کار کن، چون خمیری که روی تخته یا کاغذ معطل بماند می‌چسبد.

    > Why: مواد رویی سبک اجازه می‌دهند بخار بیرون برود، پس وسط پیتزا به‌جای خیس ماندن سفت می‌شود. مواد آبدار را اول با دستمال خشک کن و پنیر رنده‌شده‌ی خشک بریز.

9. **پیتزا را سریع روی سطح داغ بلغزان** آن را از روی تخته یا کفگیر پیتزا (پاروی تخت مخصوص پیتزا) روی سطح پخت ببر. روی تخته کمی سمولینا یا آرد بپاش، یا اگر ترجیح می‌دهی از کاغذ روغنی استفاده کن (یادداشت ایمنی پایین را ببین).

    > Why: هر بار که در فر را باز می‌کنی، گرما از دست می‌رود. سریع باش.

    > Safety: استفاده از کاغذ روغنی انتخاب خودت است. بدون کاغذ: خمیر را روی تخته یا کفگیر پیتزایی که کمی سمولینا یا آرد رویش پاشیده‌ای باز کن، بعد روی سطح داغ بلغزان. با کاغذ: حداکثر دمای چاپ‌شده روی بسته را ببین. دمای مجاز خیلی از کاغذها {{ recipes.safety.parchment_max_c.value }} درجه است که از دمای این فر کمتر است. کاغذ را از المنت‌ها و دیواره‌های فر دور نگه دار و لبه‌های اضافی‌اش را قیچی کن. اگر از کاغذ استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Safety: روغن زیتون فرابکر از حدود {{ recipes.safety.evoo_smoke_c.range.0 }} تا {{ recipes.safety.evoo_smoke_c.range.1 }} درجه شروع به دود کردن می‌کند و این فر روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه است. سطح پخت داغ را روغن نزن. داخل این خمیر روغن نیست. برای حاشیه فقط یک لایه‌ی نازک بزن و روغن زیتون تصفیه‌شده یا سبک انتخاب کن، چون کمتر دود می‌کند.
10. **{{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه بپز و آخر کار گریل را روشن کن** با گرمای بالا و پایین بپز. {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخر گریل را روشن کن تا روی پیتزا و حاشیه رنگ بگیرد. کنار فر بمان و حواست به پیتزا باشد. پیتزا روی هم نباید بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه زیر گریل بماند. اگر از کاغذ روغنی استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Why: فر {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه از بالا گرمای کافی نمی‌دهد. فر واقعی ناپولیتن خیلی داغ‌تر است، پس گریل بخشی از آن گرما را جبران می‌کند.

    > Tip: پیتزا وقتی آماده است که حاشیه پف کرده و لکه‌های قهوه‌ای تا تیره دارد و کفش سفت شده است. پیش از اینکه لکه‌ها سیاه شوند، پیتزا را بیرون بیاور.
11. **پیتزا را از فر دربیاور** اگر دوست داری، ریحان تازه و کمی روغن زیتون رویش بریز.
12. **برای پیتزای دوم صبر کن** روی چونه‌اش را بپوشان تا پیتزای اول بیرون بیاید و سطح پخت دوباره داغ شود. این کار حدود {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.0 }} تا {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.1 }} دقیقه طول می‌کشد. فقط بعد از آن چونه را باز کن.

    > Why: خمیری که روی تخته یا کاغذ معطل بماند خیس می‌شود و می‌چسبد.

## عیب‌یابی

- **حاشیه پف نکرد.** موقع باز کردن روی حاشیه فشار آورده‌ای، یا خمیر به اندازه‌ی کافی ور نیامده بود. خمیر را از وسط باز کن و به حاشیه دست نزن.
- **کف رنگ نگرفت یا نرم ماند.** سطح پخت به اندازه‌ی کافی داغ نبوده. آن را {{ recipes.oven.preheat_min.range.1 }} دقیقه داغ کن.
- **روی پیتزا کم‌رنگ ماند ولی کفش رنگ گرفت.** سطح پخت را طبقه‌ی بالاتر بگذار و {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخر گریل را روشن کن.
- **حاشیه یا روی پیتزا زیر گریل سوخت.** گریل را مدت کوتاه‌تری روشن بگذار. روی هم هیچ‌وقت بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه روشنش نکن.
- **خمیر جمع می‌شود.** گلوتن سفت است یا خمیر سرد است. بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند.
- **خمیر پاره می‌شود.** یا سرد است یا گلوتنش ضعیف است. بگذار استراحت کند، یا سوراخ را با یک تکه‌ی کوچک خمیر وصله کن.
- **بوی تند الکل یا ترشی می‌دهد.** خمیر زیادی ور آمده. دفعه‌ی بعد مخمر کمتر بریز یا زمان را کوتاه‌تر کن. در اتاق گرم، زمان ور آمدن را کوتاه کن.
- **خمیر خیلی چسبناک یا خیلی سفت است.** قسمت‌های «خمیر چسبناک است» و «خمیر خشک است» را در بخش «ورز دادن» صفحه‌ی دستور نیویورکی ببین.

## قوانین اصلی چه می‌گویند

پیتزای ناپولیتن اصل قوانینی دارد که «انجمن پیتزای اصیل ناپلی» آن‌ها را تعیین کرده است؛ انجمنی در ناپل که از پیتزای اصل محافظت می‌کند. این راهنما از واقعیت‌های زیر استفاده می‌کند. این‌ها فقط برای اطلاع‌اند و لازم نیست پیتزای خانگی تو از آن‌ها پیروی کند.

- **تخمیر:** روی هم {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.1 }} ساعت. قوانین دمایی تعیین نمی‌کنند. در ناپل خمیر در دمای اتاق می‌ماند.

- **حاشیه:** {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر.
- **فر:** {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.1 }} درجه و پخت در {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.1 }} ثانیه. فر خانگی به این دما نمی‌رسد.
