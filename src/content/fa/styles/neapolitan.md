## پیتزای آماده

پیتزای ناپولیتن وسطش نازک و نرم است و حاشیه‌ای بلند، نرم و پف‌کرده دارد. همه‌ی دماهای این سایت به درجه‌ی سانتی‌گراد است. نتیجه این‌طور است:

- **وسط:** نازک و نرم. خم می‌شود. مثل کراکر ترد نیست.
- **حاشیه (لبه‌ی پیتزا):** بلند، پرهوا و لطیف، با چند لکه‌ی قهوه‌ای تا تیره که گرما رویش می‌اندازد.
- **در خانه:** فر واقعی ناپولیتن روی {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.1 }} درجه کار می‌کند و پیتزا را در {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.1 }} ثانیه می‌پزد. فر خانگی حدود {{ recipes.oven.max_c.value }} درجه گرم می‌شود، پس پخت {{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه طول می‌کشد. نتیجه پیتزای **به سبک ناپولیتن** است، نه خود اصلش. حاشیه کمی سفت‌تر و رنگش کمتر تیره می‌شود. ولی باز هم پیتزای خیلی خوبی است.

دستور اصلی بیشتر به طعم و بافت توجه دارد تا عددهای دقیق. همه‌ی مقدارها و زمان‌های اینجا نقطه‌ی شروع‌اند. یک بار بپز، خمیر و پوسته را نگاه کن و دفعه‌ی بعد هر چه لازم است تغییر بده.

## انتخاب تخمیر

تخمیر یعنی مخمر قند را می‌خورد و گاز و طعم می‌سازد. در ناپل خمیر معمولاً {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.1 }} ساعت در دمای اتاق و با مخمر خیلی کم تخمیر می‌شود. این صفحه سه نوع تخمیر دارد. یکی را در صفحه‌ی اصلی انتخاب می‌کنی و کارت «مواد لازم» در همین صفحه مقدارهایش را نشان می‌دهد. برای امتحان یکی دیگر، بالای صفحه «تغییر» را بزن.

**تخمیر در دمای اتاق، {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت: نزدیک‌ترین به ناپل.** خمیر در دمای اتاق (حدود {{ recipes.oven.room_c.value }} درجه) ور می‌آید؛ اول یک‌تکه و بعد به شکل چونه.

- **مزیت‌ها:** در ناپل همین‌طور درستش می‌کنند. ور آمدن آرام طعم عمیقی می‌دهد.
- **عیب‌ها:** باید روزت را برنامه‌ریزی کنی و زمان‌بندی به دمای اتاقت بستگی دارد. اتاق گرم‌تر یعنی ور آمدن سریع‌تر. مقدار مخمر این تخمیر نامطمئن‌ترین مقدار این راهنماست.

**تخمیر سرد، {{ recipes.methods.cold_24h.fridge_h.value }} ساعت: برنامه‌ریزی‌اش از همه راحت‌تر است.** خمیر در یخچال (حدود {{ recipes.oven.fridge_c.range.0 }} تا {{ recipes.oven.fridge_c.range.1 }} درجه) استراحت می‌کند و مخمر آنجا آرام کار می‌کند.

- **مزیت‌ها:** طعم عمیق. اگر برنامه‌ات عوض شد، خمیر حدود یک روز بیشتر هم در یخچال می‌ماند. روز پخت کار زیادی نداری.
- **عیب‌ها:** در یخچال جا لازم داری و مقدار مخمر باید دقیق باشد. برای همین این تخمیر معمولاً از «محلول مخمر» استفاده می‌کند (وقتی لازم باشد، جدول کارت «مواد لازم» ردیف «محلول مخمر» دارد).

**تخمیر گرم، 2 ساعت: وقتی عجله داری.** خمیر را درست می‌کنی و حدود دو ساعت بعد می‌پزی.

- **مزیت‌ها:** همان روز آماده است.
- **عیب‌ها:** طعمش ساده‌تر و بیشتر شبیه نان معمولی است. از این سه تخمیر، کمترین شباهت را به اصلش دارد.
- **دست‌کم {{ recipes.methods.warm_2h.min_pizzas }} پیتزا لازم دارد.** برای یک پیتزا مخمر خشک آن‌قدر کم است که ترازوی آشپزخانه‌ای که فقط گرم کامل نشان می‌دهد، آن را درست وزن نمی‌کند. این راهنما برای مخمر تازه هم همین قاعده را نگه می‌دارد.

**خلاصه:** اگر وقت داری، برای نزدیک‌ترین نتیجه تخمیر در دمای اتاق را انتخاب کن، یا برای راحت‌ترین برنامه تخمیر سرد را. اگر می‌خواهی همین امروز بخوری، تخمیر گرم هم پیتزای خوشمزه‌ای می‌دهد.

## آرد و مخمر

**آرد.** همان آرد پیتزایی را بگیر که برای پیتزای نیویورکی می‌گیری (روی بسته‌اش اغلب «تیپو 00» نوشته شده). بخش «آرد و مخمر» در صفحه‌ی دستور نیویورکی توضیح می‌دهد پروتئین روی بسته را چطور بخوانی.

**مخمر.** کارت «مواد لازم» همان مخمری را نشان می‌دهد که در صفحه‌ی اصلی انتخاب کرده‌ای (خشک یا تازه). بخش «آرد و مخمر» در صفحه‌ی دستور نیویورکی هر دو نوع را توضیح می‌دهد. در خمیرهای کوچک، تخمیر در دمای اتاق و تخمیر سرد از محلول مخمر استفاده می‌کنند، چون مخمر برای ترازوی آشپزخانه خیلی سبک است. مرحله‌ی «مخمر را آماده کن» طرز درست کردن محلول را می‌گوید و جدول کارت «مواد لازم» نشان می‌دهد که لازمش داری یا نه.

- **شکر:** خمیر اصلی شکر ندارد. این دستور خانگی کمی شکر دارد ({{ recipes.styles.neapolitan.dough.sugar.value }} درصد وزن آرد؛ کارت «مواد لازم» مقدارش را به گرم نشان می‌دهد)، چون فر {{ recipes.oven.max_c.value }} درجه پیتزا را کمتر از فر واقعی ناپولیتن رنگ می‌اندازد. می‌توانی شکر را نریزی.
- **روغن:** هیچ. داخل این خمیر روغن نیست.

> Warning: مقدار مخمر نقطه‌ی شروع است، نه قانون ثابت. منبع‌ها برای یک برنامه‌ی یکسان تا {{ recipes.yeast.source_spread_x.value }} برابر با هم فرق دارند. مقدار درست به دمای اتاق یا یخچال و به مخمر خودت بستگی دارد. یک بار بپز، خمیر و پوسته را نگاه کن و دفعه‌ی بعد مقدار را تغییر بده.

## تخمیر در دمای اتاق {methods=room_8_12h}

خمیر را صبح درست می‌کنی و عصر می‌پزی، یا برعکس. خمیر روی هم {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت در دمای اتاق ور می‌آید. مقدارها را از جدول کارت «مواد لازم» بردار.

> Warning: دمای اتاق سرعت ور آمدن را خیلی تغییر می‌دهد. این برنامه برای اتاقی با دمای حدود {{ recipes.oven.room_c.value }} درجه است. اگر اتاقت گرم‌تر از {{ recipes.styles.new_york.practice.hot_room_c.value }} درجه است، هر دو مرحله‌ی ور آمدن را کوتاه‌تر کن و حواست به خمیر باشد.

1. **مخمر را آماده کن**
   1. آب خنک (حدود {{ recipes.methods.room_8_12h.water_temp_c.value }} درجه) را در یک کاسه‌ی بزرگ بریز. هیچ‌وقت آب داغ نریز: مخمر را می‌کشد.
   2. جدول کارت «مواد لازم» را نگاه کن.
      - **اگر جدول ردیف «محلول مخمر» دارد:** در یک لیوان جدا، یک بسته‌ی کامل {{ recipes.yeast.solution.dry.yeast_g.value }} گرمی مخمر خشک (یا نصف یک قالب {{ recipes.yeast.solution.fresh.cube_g.value }} گرمی مخمر تازه) را در {{ recipes.yeast.solution.dry.water_g.value }} گرم ({{ recipes.yeast.solution.dry.water_g.value }} میلی‌لیتر) آب ولرم ({{ recipes.yeast.solution.water_temp_c.range.0 }} تا {{ recipes.yeast.solution.water_temp_c.range.1 }} درجه) هم بزن تا هیچ گلوله‌ای نماند. {{ recipes.yeast.solution.dissolve_wait_min.value }} دقیقه صبر کن و دوباره هم بزن. بعد همان مقداری را که جدول نشان می‌دهد بلافاصله در آب خمیر بریز و باقی‌مانده را دور بریز. پیمانه‌ی مدرج هم کار می‌کند: آب و محلول مخمر تقریباً به اندازه‌ی گرمشان میلی‌لیتر حجم دارند (ستون «تقریبی» مقدارشان را به میلی‌لیتر نشان می‌دهد).
      - **اگر جدول ردیف «مخمر خشک» یا «مخمر تازه» دارد:** همان مقدار را وزن کن و در آب هم بزن. مخمر تازه را اول خرد کن. برای مخمر فوری خشک لازم نیست صبر کنی.
   3. فعلاً نمک را داخل کاسه نریز: نمکی که مستقیم به مخمر برسد کارش را کند می‌کند.
   > Why: مقدار کم مخمر برای ترازوی آشپزخانه خیلی سبک است، پس به‌جایش بخشی از محلول مخمر را وزن می‌کنی. در خمیرهای بزرگ‌تر مخمر آن‌قدر هست که مستقیم وزن شود. وقتی جدول ردیف «محلول مخمر» دارد، وزن محلول از قبل از ردیف «آب» کم شده است.

   > Tip: اگر مخمرت کهنه است یا مطمئن نیستی زنده باشد، اول امتحانش کن. کمی از مخمری را که برای این خمیر لازم نداری، در یک لیوان آب ولرم هم بزن. یک ذره شکر کمک می‌کند کف زودتر پیدا شود؛ این شکر فقط برای امتحان است. صبر کن تا روی آب کف بیاید؛ ممکن است چند دقیقه طول بکشد. اگر کف نکرد، مخمر مرده است: مخمر نو بگیر. مخمر فوری خشکی که تاریخش نگذشته، امتحان لازم ندارد.
2. **خمیر را مخلوط کن**
   1. حدود نصف آرد را بریز و هم بزن تا مخلوط صاف شود.
   2. بقیه‌ی آرد را کم‌کم بریز و بعد از هر بار هم بزن.
   3. فقط آن‌قدر هم بزن که آرد خشکی نماند.
   > Why: آردی که کم‌کم اضافه شود یکدست خیس می‌شود، پس گلوله‌ی خشک درست نمی‌شود و مخمر در خمیر پخش می‌شود.
3. **خمیر را استراحت بده**
   روی کاسه را بپوشان و خمیر را {{ recipes.methods.room_8_12h.autolyse_min.range.0 }} تا {{ recipes.methods.room_8_12h.autolyse_min.range.1 }} دقیقه به حال خودش بگذار. به این استراحت «اتولیز» می‌گویند.
   > Why: آب و آنزیم‌های آرد خودبه‌خود ساختن گلوتن را شروع می‌کنند، پس ورز کمتری لازم است.
4. **نمک را اضافه کن و ورز بده**
   1. نمک (و اگر می‌ریزی، شکر) را روی خمیر بپاش. آن‌قدر در خمیر کار کن تا یکدست شود.
   2. {{ recipes.methods.room_8_12h.knead_min.range.0 }} تا {{ recipes.methods.room_8_12h.knead_min.range.1 }} دقیقه ورز بده. بخش «ورز دادن» در صفحه‌ی دستور نیویورکی طرزش را نشان می‌دهد. روغن اضافه نکن.
   > Why: نمک گلوتن را قوی‌تر و کار مخمر را کند می‌کند. گلوتن همان شبکه‌ی کشسانی است که گاز مخمر را نگه می‌دارد.
5. **بگذار خمیر ور بیاید**
   خمیر را در ظرف دردار بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین). بگذار یک‌تکه، حدود {{ recipes.methods.room_8_12h.bulk_min.value }} دقیقه در دمای اتاق بماند، تا {{ recipes.styles.new_york.practice.rise_factor.range.0 }} تا {{ recipes.styles.new_york.practice.rise_factor.range.1 }} برابر شود. زمان فقط راهنماست، خمیر تصمیم می‌گیرد و در آشپزخانه‌ی گرم زودتر آماده می‌شود. «خواندن خمیر» را در صفحه‌ی مبانی ببین. در ظرف را بسته نگه دار تا سطح خمیر خشک نشود.
   > Why: مخمر گاز می‌سازد و گاز خمیر را بزرگ و پف‌دار می‌کند. ور آمدن آرام در دمای اتاق طعم می‌سازد.

   > Tip: ظرفی بردار که خمیر بتواند دو برابر شود و به در ظرف نخورد. سطح خمیر را بیرون ظرف با چسب کاغذی یا ماژیک علامت بزن تا ببینی چقدر بزرگ شده است.
6. **خمیر را تقسیم و چونه کن**
   1. کل خمیر را روی ترازو بگذار. وزنش باید نزدیک «مجموع خمیر» در جدول باشد.
   2. این وزن را بر تعداد پیتزاها تقسیم کن. از خمیر تکه‌های هم‌وزن ببر.
   3. هر تکه را چونه کن: لبه‌ها را به وسط جمع کن، برش گردان و با کف دست روی میز بچرخان تا سطحش کشیده و صاف شود. هر چونه را در یک ظرف دردار جدا بگذار.
   > Why: چونه‌های هم‌وزن یکنواخت می‌پزند و پیتزاهای هم‌اندازه می‌دهند. ترازو از چشم دقیق‌تر است. سطح کشیده گاز را داخل نگه می‌دارد و چونه بعداً راحت‌تر باز می‌شود.
7. **چونه‌ها را استراحت بده**
   بگذار چونه‌ها با در بسته حدود {{ recipes.methods.room_8_12h.final_rest_min.value }} دقیقه بمانند، تا نرم و پف‌دار شوند و انگشت آردی که روی خمیر فشار می‌دهی جای فرورفتگی را آرام پر کند. «خواندن خمیر» را در صفحه‌ی مبانی ببین. کل ور آمدن، از مخلوط کردن تا پخت، {{ recipes.methods.room_8_12h.total_ferment_h.range.0 }} تا {{ recipes.methods.room_8_12h.total_ferment_h.range.1 }} ساعت طول می‌کشد.
   > Why: خمیر در چونه‌ها آرام به ور آمدن ادامه می‌دهد و گلوتن شل می‌شود. چونه‌ای که استراحت کرده راحت باز می‌شود و جمع نمی‌شود.
8. **فر و سطح پخت را داغ کن**
   این کار را {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه پیش از پخت انجام بده، وقتی چونه‌ها هنوز در حال استراحت‌اند. سطح پخت (سنگ پیتزا، فولاد پخت یا سینی چدنی) را در طبقه‌ی بالای فر بگذار، یعنی حدود یک‌سوم بالایی فر. فر را روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه، با گرمای بالا و پایین و **بدون فن** تنظیم کن.
   > Why: سطحی که کامل داغ نشده، کف پیتزا را رنگ‌پریده و نرم می‌کند. گرمای بالا و پایین گرما را مستقیم از زیر به سطح پخت می‌رساند. در حالت فن، المنت پایین اغلب خاموش است و هوای در حال حرکت روی پیتزا را زودتر از کفش خشک می‌کند و رنگ می‌اندازد. اگر فرت حالت پیتزا دارد (فن همراه با گرمای پایین)، می‌توانی امتحانش کنی و حواست به روی پیتزا باشد.
9. **چونه را باز کن**
   حدود {{ recipes.timeline.shape_lead_min.value }} دقیقه پیش از پخت شروع کن. تا آن موقع فر داغ است و سطح پخت تقریباً {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه‌ی کاملش را گرم شده است. روی بقیه‌ی چونه‌ها پوشیده بماند.
   1. حدود {{ recipes.styles.new_york.practice.bench_flour_g.value }} گرم آرد (یا سمولینا: دانه‌های درشتش کمک می‌کنند خمیر راحت سُر بخورد و خمیری نشود؛ واژه‌نامه را ببین) روی میز بپاش. چونه را رویش بگذار و با نوک انگشت‌ها از وسط به بیرون فشار بده. **به حاشیه‌ی {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متری دست نزن.**
   2. خمیر را با دو دست بکش و همزمان بچرخان تا به اندازه‌ای برسد که در صفحه‌ی اصلی انتخاب کرده‌ای (بالای همین صفحه نوشته شده).
   3. اگر خمیر جمع شد، بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند و بعد دوباره بکشش.
   > Why: حاشیه‌ی دست‌نخورده هوایش را نگه می‌دارد، پس در فر پف می‌کند. حاشیه‌ی بلند و نرم نشانه‌ی پیتزای ناپولیتن است.

   > Warning: از وردنه استفاده نکن. وردنه هوای خمیر را بیرون می‌دهد و حاشیه پف نمی‌کند.
10. **روی پیتزا را بچین**
    ساده بچین.
    1. خمیر بازشده را روی تخته یا کفگیر پیتزا (پاروی تخت مخصوص پیتزا) بگذار که کمی سمولینا یا آرد رویش پاشیده‌ای، یا روی کاغذ روغنی (یادداشت‌های ایمنی مرحله‌ی «پیتزا را داخل فر بلغزان» را ببین).
    2. یک لایه‌ی نازک سس پخش کن و حاشیه را (حدود {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر) خالی بگذار.
    3. پنیر و هر چیز دیگری که دوست داری رویش بریز. روی پیتزا زیاد مواد نریز.
    4. حاشیه را با کمی روغن زیتون چرب کن. سریع کار کن، چون خمیری که روی تخته یا کاغذ معطل بماند می‌چسبد.
    > Why: مواد رویی سبک اجازه می‌دهند بخار بیرون برود، پس وسط پیتزا به‌جای خیس ماندن سفت می‌شود. مواد زیاد پیتزا را سنگین هم می‌کند و لغزاندنش سخت می‌شود. مواد آبدار را اول با دستمال خشک کن و پنیر رنده‌شده‌ی خشک بریز.
11. **پیتزا را داخل فر بلغزان**
    پیتزا را با یک حرکت سریع از روی تخته یا کفگیر روی سطح پخت بلغزان و در فر را ببند.
    > Why: هر بار که در فر را باز می‌کنی، گرما از دست می‌رود. سریع باش.

    > Safety: استفاده از کاغذ روغنی (کاغذ مخصوص فر) انتخاب خودت است. بدون کاغذ: خمیر را روی تخته یا کفگیر پیتزایی که کمی سمولینا یا آرد رویش پاشیده‌ای باز کن، بعد روی سطح داغ بلغزان. با کاغذ: حداکثر دمای چاپ‌شده روی بسته را ببین. دمای مجاز خیلی از کاغذها {{ recipes.safety.parchment_max_c.value }} درجه است که از دمای این فر کمتر است. کاغذ را از المنت‌ها و دیواره‌های فر دور نگه دار و لبه‌های اضافی‌اش را قیچی کن. از کاغذ مومی (کاغذی که لایه‌ی موم دارد و برای فر ساخته نشده) استفاده نکن. اگر دمای مجاز کاغذت از دمای فر کمتر است، بعد از {{ recipes.safety.parchment_pull_min.range.0 }} تا {{ recipes.safety.parchment_pull_min.range.1 }} دقیقه‌ی اول، وقتی کف پیتزا خودش را گرفت، کاغذ را از زیرش بیرون بکش. اگر از کاغذ استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Safety: روغن زیتون فرابکر از حدود {{ recipes.safety.evoo_smoke_c.range.0 }} تا {{ recipes.safety.evoo_smoke_c.range.1 }} درجه شروع به دود کردن می‌کند و این فر روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه است. سطح پخت داغ را روغن نزن. داخل این خمیر روغن نیست. برای حاشیه فقط یک لایه‌ی نازک بزن و روغن زیتون تصفیه‌شده یا سبک انتخاب کن، چون کمتر دود می‌کند.

    > Safety: دستکش فر بپوش. طبقه‌ی فر را فقط کمی بیرون بکش تا پیتزا را رویش بلغزانی، و هیچ‌وقت به سطح پخت دست نزن؛ تا مدت زیادی بعد از خاموش کردن فر هم داغ می‌ماند.
12. **بپز**
    {{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه با گرمای بالا و پایین بپز. در {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخرِ همین زمان، گریل را روشن کن تا روی پیتزا و حاشیه رنگ بگیرد. کنار فر بمان و حواست به پیتزا باشد. پیتزا روی هم هیچ‌وقت نباید بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه زیر گریل بماند. اگر از کاغذ روغنی استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.
    > Why: فر {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه از بالا گرمای کافی نمی‌دهد. فر واقعی ناپولیتن خیلی داغ‌تر است، پس گریل بخشی از آن گرما را جبران می‌کند.

    > Tip: پیتزا وقتی آماده است که حاشیه پف کرده و لکه‌های قهوه‌ای تا تیره دارد و کفش سفت شده است. پیش از اینکه لکه‌ها سیاه شوند، پیتزا را بیرون بیاور.
13. **پیتزا را دربیاور**
    پیتزا را با کفگیر یا با دستکش فر بیرون بیاور. اگر دوست داری، ریحان تازه و کمی روغن زیتون رویش بریز.
14. **برای پیتزای دوم صبر کن**
    فر را دوباره روی گرمای بالا و پایین بگذار. {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.0 }} تا {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.1 }} دقیقه صبر کن تا سطح پخت دوباره داغ شود. تا آن موقع روی چونه‌ی بعدی پوشیده بماند و فقط بعد از آن بازش کن.
    > Why: خمیری که روی تخته یا کاغذ معطل بماند خیس می‌شود و می‌چسبد.

## تخمیر سرد {methods=cold_24h}

خمیر را یک روز پیش از پخت درست می‌کنی. مقدارها را از جدول کارت «مواد لازم» بردار. روز اول با مرحله‌ی «خمیر را سرد کن» تمام می‌شود. روز پخت با مرحله‌ی «خمیر را از یخچال دربیاور» شروع می‌شود.

> Tip: اگر جدول ردیف «محلول مخمر» دارد، محلول را درست پیش از استفاده آماده کن. درست پیش از برداشتن مقدار لازم دوباره هم بزن، چون مخمر ته ظرف می‌نشیند. باقی‌مانده‌اش را دور بریز. هیچ منبعی نمی‌گوید محلول مخمر تا کی سالم می‌ماند، برای همین این راهنما مدت نگهداری برایش نمی‌دهد.

1. **مخمر را آماده کن**
   1. آب سرد (حدود {{ recipes.methods.cold_24h.water_temp_c.value }} درجه) را در یک کاسه‌ی بزرگ بریز.
   2. جدول کارت «مواد لازم» را نگاه کن.
      - **اگر جدول ردیف «محلول مخمر» دارد:** در یک لیوان جدا، یک بسته‌ی کامل {{ recipes.yeast.solution.dry.yeast_g.value }} گرمی مخمر خشک (یا نصف یک قالب {{ recipes.yeast.solution.fresh.cube_g.value }} گرمی مخمر تازه) را در {{ recipes.yeast.solution.dry.water_g.value }} گرم ({{ recipes.yeast.solution.dry.water_g.value }} میلی‌لیتر) آب ولرم ({{ recipes.yeast.solution.water_temp_c.range.0 }} تا {{ recipes.yeast.solution.water_temp_c.range.1 }} درجه) هم بزن تا هیچ گلوله‌ای نماند. {{ recipes.yeast.solution.dissolve_wait_min.value }} دقیقه صبر کن و دوباره هم بزن. بعد همان مقداری را که جدول نشان می‌دهد بلافاصله در آب خمیر بریز و باقی‌مانده را دور بریز. پیمانه‌ی مدرج هم کار می‌کند: آب و محلول مخمر تقریباً به اندازه‌ی گرمشان میلی‌لیتر حجم دارند (ستون «تقریبی» مقدارشان را به میلی‌لیتر نشان می‌دهد).
      - **اگر جدول ردیف «مخمر خشک» یا «مخمر تازه» دارد:** همان مقدار را وزن کن و در آب هم بزن. مخمر تازه را اول خرد کن. برای مخمر فوری خشک لازم نیست صبر کنی.
   3. فعلاً نمک را داخل کاسه نریز: نمکی که مستقیم به مخمر برسد کارش را کند می‌کند.
   > Why: مقدار کم مخمر برای ترازوی آشپزخانه خیلی سبک است، پس به‌جایش بخشی از محلول مخمر را وزن می‌کنی. در خمیرهای بزرگ‌تر مخمر آن‌قدر هست که مستقیم وزن شود. وقتی جدول ردیف «محلول مخمر» دارد، وزن محلول از قبل از ردیف «آب» کم شده است.

   > Tip: اگر مخمرت کهنه است یا مطمئن نیستی زنده باشد، اول امتحانش کن. کمی از مخمری را که برای این خمیر لازم نداری، در یک لیوان آب ولرم هم بزن. یک ذره شکر کمک می‌کند کف زودتر پیدا شود؛ این شکر فقط برای امتحان است. صبر کن تا روی آب کف بیاید؛ ممکن است چند دقیقه طول بکشد. اگر کف نکرد، مخمر مرده است: مخمر نو بگیر. مخمر فوری خشکی که تاریخش نگذشته، امتحان لازم ندارد.
2. **خمیر را مخلوط کن**
   1. حدود نصف آرد را بریز و هم بزن تا مخلوط صاف شود.
   2. بقیه‌ی آرد را کم‌کم بریز و بعد از هر بار هم بزن.
   3. فقط آن‌قدر هم بزن که آرد خشکی نماند. خمیر خنک می‌شود، نه سرد؛ اشکالی ندارد.
   > Why: آردی که کم‌کم اضافه شود یکدست خیس می‌شود، پس گلوله‌ی خشک درست نمی‌شود و مخمر در خمیر پخش می‌شود.
3. **خمیر را استراحت بده**
   روی کاسه را بپوشان و خمیر را {{ recipes.methods.cold_24h.autolyse_min.range.0 }} تا {{ recipes.methods.cold_24h.autolyse_min.range.1 }} دقیقه به حال خودش بگذار. به این استراحت «اتولیز» می‌گویند.
   > Why: آب و آنزیم‌های آرد خودبه‌خود ساختن گلوتن را شروع می‌کنند، پس ورز کمتری لازم است.
4. **نمک را اضافه کن و ورز بده**
   1. نمک (و اگر می‌ریزی، شکر) را روی خمیر بپاش. آن‌قدر در خمیر کار کن تا یکدست شود.
   2. {{ recipes.methods.cold_24h.knead_min.range.0 }} تا {{ recipes.methods.cold_24h.knead_min.range.1 }} دقیقه ورز بده. بخش «ورز دادن» در صفحه‌ی دستور نیویورکی طرزش را نشان می‌دهد. روغن اضافه نکن.
   - اگر کشیدن و تا کردن را ترجیح می‌دهی، ورز نده. این کار را در مرحله‌ی بعد انجام می‌دهی (قسمت «کشیدن و تا کردن» در بخش «ورز دادن» صفحه‌ی دستور نیویورکی را ببین).
   > Why: نمک گلوتن را قوی‌تر و کار مخمر را کند می‌کند.
5. **بگذار خمیر ور بیاید**
   1. خمیر را در ظرف دردار بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین).
   2. بگذار در دمای حدود {{ recipes.oven.room_c.value }} درجه، حدود {{ recipes.methods.cold_24h.room_rest_min.range.0 }} تا {{ recipes.methods.cold_24h.room_rest_min.range.1 }} دقیقه بماند. زمان فقط راهنماست: در آشپزخانه‌ی گرم زودتر و در آشپزخانه‌ی سرد دیرتر می‌شود. وقتی خمیر حدود {{ recipes.styles.new_york.practice.cold_rise_pct.value }} درصد بزرگ‌تر شد، آن را در یخچال بگذار. «خواندن خمیر» را در صفحه‌ی مبانی ببین.
   - اگر کشیدن و تا کردن را انتخاب کرده‌ای، در همین مدت {{ recipes.methods.cold_24h.stretch_fold.rounds.value }} دور انجام بده: دور اول را همین حالا، بعد هر {{ recipes.methods.cold_24h.stretch_fold.gap_min.value }} دقیقه یک دور. دورها همان‌قدر وقت می‌گیرند که می‌گیرند، پس همه را انجام بده. بعد از دور آخر خمیر را نگاه کن و وقتی حدود {{ recipes.styles.new_york.practice.cold_rise_pct.value }} درصد بزرگ‌تر شد، آن را در یخچال بگذار. اگر هنوز به آنجا نرسیده، کمی بیشتر صبر کن.
   > Why: مخمر پیش از رفتن به سرما یک شروع گرم و کوتاه لازم دارد.

   > Tip: ظرفی بردار که خمیر بتواند دو برابر شود و به در ظرف نخورد. سطح خمیر را بیرون ظرف با چسب کاغذی یا ماژیک علامت بزن تا ببینی چقدر بزرگ شده است.
6. **خمیر را تقسیم و چونه کن**
   1. کل خمیر را روی ترازو بگذار. وزنش باید نزدیک «مجموع خمیر» در جدول باشد.
   2. این وزن را بر تعداد پیتزاها تقسیم کن. از خمیر تکه‌های هم‌وزن ببر.
   3. هر تکه را چونه کن: لبه‌ها را به وسط جمع کن، برش گردان و با کف دست روی میز بچرخان تا سطحش کشیده و صاف شود. هر چونه را در یک ظرف دردار جدا بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین).
   > Why: چونه‌های هم‌وزن یکنواخت می‌پزند و پیتزاهای هم‌اندازه می‌دهند. ترازو از چشم دقیق‌تر است. سطح کشیده گاز را داخل نگه می‌دارد و چونه بعداً راحت‌تر باز می‌شود.
7. **خمیر را سرد کن**
   ظرف‌ها را {{ recipes.methods.cold_24h.fridge_h.value }} ساعت در یخچال بگذار.
   > Why: در یخچال مخمر آرام کار می‌کند و آنزیم‌ها فرصت دارند طعم بسازند. نتیجه طعم عمیق‌تر و رنگ‌گیری بهتر است.
8. **خمیر را از یخچال دربیاور**
   روز پخت، ظرف‌ها را حدود {{ recipes.methods.cold_24h.take_out_lead_min.range.0 }} تا {{ recipes.methods.cold_24h.take_out_lead_min.range.1 }} دقیقه پیش از باز کردن چونه‌ها بیرون بیاور. در ظرف‌ها را باز نکن. چونه وقتی آماده‌ی باز کردن است که نرم باشد و انگشت آردی که روی خمیر فشار می‌دهی جای فرورفتگی را آرام پر کند. «خواندن خمیر» را در صفحه‌ی مبانی ببین.
   > Why: خمیر سرد خوب کش نمی‌آید و پاره می‌شود. این رایج‌ترین اشتباه در تخمیر سرد است.
9. **فر و سطح پخت را داغ کن**
   این کار را {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه پیش از پخت انجام بده، همان وقتی که خمیر دارد از سرما درمی‌آید. سطح پخت (سنگ پیتزا، فولاد پخت یا سینی چدنی) را در طبقه‌ی بالای فر بگذار، یعنی حدود یک‌سوم بالایی فر. فر را روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه، با گرمای بالا و پایین و **بدون فن** تنظیم کن.
   > Why: سطحی که کامل داغ نشده، کف پیتزا را رنگ‌پریده و نرم می‌کند. گرمای بالا و پایین گرما را مستقیم از زیر به سطح پخت می‌رساند. در حالت فن، المنت پایین اغلب خاموش است و هوای در حال حرکت روی پیتزا را زودتر از کفش خشک می‌کند و رنگ می‌اندازد. اگر فرت حالت پیتزا دارد (فن همراه با گرمای پایین)، می‌توانی امتحانش کنی و حواست به روی پیتزا باشد.
10. **چونه را باز کن**
    حدود {{ recipes.timeline.shape_lead_min.value }} دقیقه پیش از پخت شروع کن. تا آن موقع فر داغ است و سطح پخت تقریباً {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه‌ی کاملش را گرم شده است. روی بقیه‌ی چونه‌ها پوشیده بماند.
    1. حدود {{ recipes.styles.new_york.practice.bench_flour_g.value }} گرم آرد (یا سمولینا: دانه‌های درشتش کمک می‌کنند خمیر راحت سُر بخورد و خمیری نشود؛ واژه‌نامه را ببین) روی میز بپاش. چونه را رویش بگذار و با نوک انگشت‌ها از وسط به بیرون فشار بده. **به حاشیه‌ی {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متری دست نزن.**
    2. خمیر را با دو دست بکش و همزمان بچرخان تا به اندازه‌ای برسد که در صفحه‌ی اصلی انتخاب کرده‌ای (بالای همین صفحه نوشته شده).
    3. اگر خمیر جمع شد، بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند و بعد دوباره بکشش.
    > Why: حاشیه‌ی دست‌نخورده هوایش را نگه می‌دارد، پس در فر پف می‌کند. حاشیه‌ی بلند و نرم نشانه‌ی پیتزای ناپولیتن است.

    > Warning: از وردنه استفاده نکن. وردنه هوای خمیر را بیرون می‌دهد و حاشیه پف نمی‌کند.
11. **روی پیتزا را بچین**
    ساده بچین.
    1. خمیر بازشده را روی تخته یا کفگیر پیتزا (پاروی تخت مخصوص پیتزا) بگذار که کمی سمولینا یا آرد رویش پاشیده‌ای، یا روی کاغذ روغنی (یادداشت‌های ایمنی مرحله‌ی «پیتزا را داخل فر بلغزان» را ببین).
    2. یک لایه‌ی نازک سس پخش کن و حاشیه را (حدود {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر) خالی بگذار.
    3. پنیر و هر چیز دیگری که دوست داری رویش بریز. روی پیتزا زیاد مواد نریز.
    4. حاشیه را با کمی روغن زیتون چرب کن. سریع کار کن، چون خمیری که روی تخته یا کاغذ معطل بماند می‌چسبد.
    > Why: مواد رویی سبک اجازه می‌دهند بخار بیرون برود، پس وسط پیتزا به‌جای خیس ماندن سفت می‌شود. مواد زیاد پیتزا را سنگین هم می‌کند و لغزاندنش سخت می‌شود. مواد آبدار را اول با دستمال خشک کن و پنیر رنده‌شده‌ی خشک بریز.
12. **پیتزا را داخل فر بلغزان**
    پیتزا را با یک حرکت سریع از روی تخته یا کفگیر روی سطح پخت بلغزان و در فر را ببند.
    > Why: هر بار که در فر را باز می‌کنی، گرما از دست می‌رود. سریع باش.

    > Safety: استفاده از کاغذ روغنی (کاغذ مخصوص فر) انتخاب خودت است. بدون کاغذ: خمیر را روی تخته یا کفگیر پیتزایی که کمی سمولینا یا آرد رویش پاشیده‌ای باز کن، بعد روی سطح داغ بلغزان. با کاغذ: حداکثر دمای چاپ‌شده روی بسته را ببین. دمای مجاز خیلی از کاغذها {{ recipes.safety.parchment_max_c.value }} درجه است که از دمای این فر کمتر است. کاغذ را از المنت‌ها و دیواره‌های فر دور نگه دار و لبه‌های اضافی‌اش را قیچی کن. از کاغذ مومی (کاغذی که لایه‌ی موم دارد و برای فر ساخته نشده) استفاده نکن. اگر دمای مجاز کاغذت از دمای فر کمتر است، بعد از {{ recipes.safety.parchment_pull_min.range.0 }} تا {{ recipes.safety.parchment_pull_min.range.1 }} دقیقه‌ی اول، وقتی کف پیتزا خودش را گرفت، کاغذ را از زیرش بیرون بکش. اگر از کاغذ استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Safety: روغن زیتون فرابکر از حدود {{ recipes.safety.evoo_smoke_c.range.0 }} تا {{ recipes.safety.evoo_smoke_c.range.1 }} درجه شروع به دود کردن می‌کند و این فر روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه است. سطح پخت داغ را روغن نزن. داخل این خمیر روغن نیست. برای حاشیه فقط یک لایه‌ی نازک بزن و روغن زیتون تصفیه‌شده یا سبک انتخاب کن، چون کمتر دود می‌کند.

    > Safety: دستکش فر بپوش. طبقه‌ی فر را فقط کمی بیرون بکش تا پیتزا را رویش بلغزانی، و هیچ‌وقت به سطح پخت دست نزن؛ تا مدت زیادی بعد از خاموش کردن فر هم داغ می‌ماند.
13. **بپز**
    {{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه با گرمای بالا و پایین بپز. در {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخرِ همین زمان، گریل را روشن کن تا روی پیتزا و حاشیه رنگ بگیرد. کنار فر بمان و حواست به پیتزا باشد. پیتزا روی هم هیچ‌وقت نباید بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه زیر گریل بماند. اگر از کاغذ روغنی استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.
    > Why: فر {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه از بالا گرمای کافی نمی‌دهد. فر واقعی ناپولیتن خیلی داغ‌تر است، پس گریل بخشی از آن گرما را جبران می‌کند.

    > Tip: پیتزا وقتی آماده است که حاشیه پف کرده و لکه‌های قهوه‌ای تا تیره دارد و کفش سفت شده است. پیش از اینکه لکه‌ها سیاه شوند، پیتزا را بیرون بیاور.
14. **پیتزا را دربیاور**
    پیتزا را با کفگیر یا با دستکش فر بیرون بیاور. اگر دوست داری، ریحان تازه و کمی روغن زیتون رویش بریز.
15. **برای پیتزای دوم صبر کن**
    فر را دوباره روی گرمای بالا و پایین بگذار. {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.0 }} تا {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.1 }} دقیقه صبر کن تا سطح پخت دوباره داغ شود. تا آن موقع روی چونه‌ی بعدی پوشیده بماند و فقط بعد از آن بازش کن.
    > Why: خمیری که روی تخته یا کاغذ معطل بماند خیس می‌شود و می‌چسبد.

## تخمیر گرم، 2 ساعت {methods=warm_2h}

خمیر را درست می‌کنی و حدود دو ساعت بعد می‌پزی. مقدارها را از جدول کارت «مواد لازم» بردار.

> Warning: این تخمیر دست‌کم {{ recipes.methods.warm_2h.min_pizzas }} پیتزا لازم دارد. برای یک پیتزا مخمر خشک آن‌قدر کم است که ترازوی آشپزخانه‌ای که فقط گرم کامل نشان می‌دهد، آن را درست وزن نمی‌کند. این راهنما برای مخمر تازه هم همین قاعده را دارد. برای یک پیتزا تخمیر دیگری انتخاب کن.

1. **مخمر را آماده کن**
   1. آب ولرم (حدود {{ recipes.methods.warm_2h.water_temp_c.value }} درجه) را در یک کاسه‌ی بزرگ بریز.
   2. مقدار ردیف «مخمر خشک» یا «مخمر تازه» را از جدول بردار و وزن کن.
   3. مخمر تازه را اول خرد کن، بعد مخمر را در آب هم بزن. برای مخمر فوری خشک لازم نیست صبر کنی.
   4. فعلاً نمک را داخل کاسه نریز: نمکی که مستقیم به مخمر برسد کارش را کند می‌کند.
   > Why: مخمر بین {{ recipes.styles.new_york.practice.yeast_works_c.range.0 }} تا {{ recipes.styles.new_york.practice.yeast_works_c.range.1 }} درجه تند کار می‌کند و از حدود {{ recipes.styles.new_york.practice.yeast_dies_c.value }} درجه شروع به مردن می‌کند، پس هیچ‌وقت آب داغ نریز. آب ولرم روی مچ دست فقط کمی گرم حس می‌شود، خنک‌تر از آب حمام.

   > Tip: اگر مخمرت کهنه است یا مطمئن نیستی زنده باشد، اول امتحانش کن. کمی از مخمری را که برای این خمیر لازم نداری، در یک لیوان آب ولرم هم بزن. یک ذره شکر کمک می‌کند کف زودتر پیدا شود؛ این شکر فقط برای امتحان است. صبر کن تا روی آب کف بیاید؛ ممکن است چند دقیقه طول بکشد. اگر کف نکرد، مخمر مرده است: مخمر نو بگیر. مخمر فوری خشکی که تاریخش نگذشته، امتحان لازم ندارد.
2. **خمیر را مخلوط کن**
   1. حدود نصف آرد را بریز و هم بزن تا مخلوط صاف شود.
   2. بقیه‌ی آرد را کم‌کم بریز و بعد از هر بار هم بزن.
   3. فقط آن‌قدر هم بزن که آرد خشکی نماند.
   > Why: آردی که کم‌کم اضافه شود یکدست خیس می‌شود، پس گلوله‌ی خشک درست نمی‌شود و مخمر در خمیر پخش می‌شود.
3. **نمک را اضافه کن و ورز بده**
   1. نمک (و اگر می‌ریزی، شکر) را روی خمیر بپاش. آن‌قدر در خمیر کار کن تا یکدست شود.
   2. {{ recipes.methods.warm_2h.knead_min.value }} دقیقه ورز بده. بخش «ورز دادن» در صفحه‌ی دستور نیویورکی طرزش را نشان می‌دهد. روغن اضافه نکن.
   > Why: وقت کم است، پس گلوتنی را که در استراحت طولانی خودبه‌خود ساخته می‌شد باید با ورز بسازی. نمک گلوتن را قوی‌تر و کار مخمر را کند می‌کند.
4. **بگذار خمیر ور بیاید**
   1. خمیر را در ظرف دردار بگذار (بخش «ظرف، روغن و پوشش» در صفحه‌ی دستور نیویورکی را ببین).
   2. بگذار در جای گرم، با دمای {{ recipes.styles.new_york.practice.warm_place_c.range.0 }} تا {{ recipes.styles.new_york.practice.warm_place_c.range.1 }} درجه، حدود {{ recipes.methods.warm_2h.bulk_min.range.0 }} تا {{ recipes.methods.warm_2h.bulk_min.range.1 }} دقیقه بماند. فر خاموش با چراغ روشن جای خوبی است.
   3. خمیر باید {{ recipes.styles.new_york.practice.rise_factor.range.0 }} تا {{ recipes.styles.new_york.practice.rise_factor.range.1 }} برابر شود. اگر جای گرم نداری، ور آمدن ممکن است تا {{ recipes.methods.warm_2h.bulk_slow_max_min.value }} دقیقه طول بکشد: زمان فقط راهنماست، پس به اندازه‌ی خمیر نگاه کن، نه به ساعت. «خواندن خمیر» را در صفحه‌ی مبانی ببین.
   > Why: مخمر گاز می‌سازد و گاز خمیر را بزرگ می‌کند. همین هوا باعث می‌شود حاشیه در فر پف کند.

   > Tip: ظرفی بردار که خمیر بتواند دو برابر شود و به در ظرف نخورد. سطح خمیر را بیرون ظرف با چسب کاغذی یا ماژیک علامت بزن تا ببینی چقدر بزرگ شده است.
5. **فر و سطح پخت را داغ کن**
   این کار را حدود نیمه‌ی زمان ور آمدن انجام بده تا وقتی چونه‌ها آماده شدند، سطح پخت داغ باشد.
   1. اگر خمیر داخل فر ور می‌آید، اول آن را بیرون بیاور. ظرف یا در پلاستیکی در فری که گرم می‌شود آب می‌شود.
   2. سطح پخت (سنگ پیتزا، فولاد پخت یا سینی چدنی) را در طبقه‌ی بالای فر بگذار، یعنی حدود یک‌سوم بالایی فر.
   3. فر را روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه، با گرمای بالا و پایین و **بدون فن** تنظیم کن.
   > Why: سطح پخت {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه لازم دارد تا کامل داغ شود. سطحی که کامل داغ نشده، کف پیتزا را رنگ‌پریده و نرم می‌کند. گرمای بالا و پایین گرما را مستقیم از زیر به سطح پخت می‌رساند. در حالت فن، المنت پایین اغلب خاموش است و هوای در حال حرکت روی پیتزا را زودتر از کفش خشک می‌کند و رنگ می‌اندازد. اگر فرت حالت پیتزا دارد (فن همراه با گرمای پایین)، می‌توانی امتحانش کنی و حواست به روی پیتزا باشد.
6. **خمیر را تقسیم و چونه کن**
   1. کل خمیر را روی ترازو بگذار. وزنش باید نزدیک «مجموع خمیر» در جدول باشد.
   2. این وزن را بر تعداد پیتزاها تقسیم کن. از خمیر تکه‌های هم‌وزن ببر.
   3. هر تکه را چونه کن: لبه‌ها را به وسط جمع کن، برش گردان و با کف دست روی میز بچرخان تا سطحش کشیده و صاف شود.
   > Why: چونه‌های هم‌وزن یکنواخت می‌پزند و پیتزاهای هم‌اندازه می‌دهند. ترازو از چشم دقیق‌تر است. سطح کشیده گاز را داخل نگه می‌دارد و چونه بعداً راحت‌تر باز می‌شود.
7. **چونه‌ها را استراحت بده**
   روی چونه‌ها را بپوشان (ظرف دردار یا یک کاسه‌ی وارونه خوب است) و بگذار حدود {{ recipes.methods.warm_2h.final_rest_min.range.0 }} تا {{ recipes.methods.warm_2h.final_rest_min.range.1 }} دقیقه بمانند، تا نرم و شل شوند. خمیر تصمیم می‌گیرد، نه ساعت. «خواندن خمیر» را در صفحه‌ی مبانی ببین. فر همچنان دارد گرم می‌شود.
   > Why: گلوتن شل می‌شود. چونه‌ای که استراحت کرده راحت باز می‌شود و جمع نمی‌شود.
8. **چونه را باز کن**
   حدود {{ recipes.timeline.shape_lead_min.value }} دقیقه پیش از پخت شروع کن. تا آن موقع فر داغ است و سطح پخت تقریباً {{ recipes.oven.preheat_min.range.0 }} تا {{ recipes.oven.preheat_min.range.1 }} دقیقه‌ی کاملش را گرم شده است. روی بقیه‌ی چونه‌ها پوشیده بماند.
   1. حدود {{ recipes.styles.new_york.practice.bench_flour_g.value }} گرم آرد (یا سمولینا: دانه‌های درشتش کمک می‌کنند خمیر راحت سُر بخورد و خمیری نشود؛ واژه‌نامه را ببین) روی میز بپاش. چونه را رویش بگذار و با نوک انگشت‌ها از وسط به بیرون فشار بده. **به حاشیه‌ی {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متری دست نزن.**
   2. خمیر را با دو دست بکش و همزمان بچرخان تا به اندازه‌ای برسد که در صفحه‌ی اصلی انتخاب کرده‌ای (بالای همین صفحه نوشته شده).
   3. اگر خمیر جمع شد، بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند و بعد دوباره بکشش.
   > Why: حاشیه‌ی دست‌نخورده هوایش را نگه می‌دارد، پس در فر پف می‌کند. حاشیه‌ی بلند و نرم نشانه‌ی پیتزای ناپولیتن است.

   > Warning: از وردنه استفاده نکن. وردنه هوای خمیر را بیرون می‌دهد و حاشیه پف نمی‌کند.
9. **روی پیتزا را بچین**
   ساده بچین.
   1. خمیر بازشده را روی تخته یا کفگیر پیتزا (پاروی تخت مخصوص پیتزا) بگذار که کمی سمولینا یا آرد رویش پاشیده‌ای، یا روی کاغذ روغنی (یادداشت‌های ایمنی مرحله‌ی «پیتزا را داخل فر بلغزان» را ببین).

   3. پنیر و هر چیز دیگری که دوست داری رویش بریز. روی پیتزا زیاد مواد نریز.
   4. حاشیه را با کمی روغن زیتون چرب کن. سریع کار کن، چون خمیری که روی تخته یا کاغذ معطل بماند می‌چسبد.
   > Why: مواد رویی سبک اجازه می‌دهند بخار بیرون برود، پس وسط پیتزا به‌جای خیس ماندن سفت می‌شود. مواد زیاد پیتزا را سنگین هم می‌کند و لغزاندنش سخت می‌شود. مواد آبدار را اول با دستمال خشک کن و پنیر رنده‌شده‌ی خشک بریز.
10. **پیتزا را داخل فر بلغزان**
    پیتزا را با یک حرکت سریع از روی تخته یا کفگیر روی سطح پخت بلغزان و در فر را ببند.
    > Why: هر بار که در فر را باز می‌کنی، گرما از دست می‌رود. سریع باش.

    > Safety: استفاده از کاغذ روغنی (کاغذ مخصوص فر) انتخاب خودت است. بدون کاغذ: خمیر را روی تخته یا کفگیر پیتزایی که کمی سمولینا یا آرد رویش پاشیده‌ای باز کن، بعد روی سطح داغ بلغزان. با کاغذ: حداکثر دمای چاپ‌شده روی بسته را ببین. دمای مجاز خیلی از کاغذها {{ recipes.safety.parchment_max_c.value }} درجه است که از دمای این فر کمتر است. کاغذ را از المنت‌ها و دیواره‌های فر دور نگه دار و لبه‌های اضافی‌اش را قیچی کن. از کاغذ مومی (کاغذی که لایه‌ی موم دارد و برای فر ساخته نشده) استفاده نکن. اگر دمای مجاز کاغذت از دمای فر کمتر است، بعد از {{ recipes.safety.parchment_pull_min.range.0 }} تا {{ recipes.safety.parchment_pull_min.range.1 }} دقیقه‌ی اول، وقتی کف پیتزا خودش را گرفت، کاغذ را از زیرش بیرون بکش. اگر از کاغذ استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.

    > Safety: روغن زیتون فرابکر از حدود {{ recipes.safety.evoo_smoke_c.range.0 }} تا {{ recipes.safety.evoo_smoke_c.range.1 }} درجه شروع به دود کردن می‌کند و این فر روی {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه است. سطح پخت داغ را روغن نزن. داخل این خمیر روغن نیست. برای حاشیه فقط یک لایه‌ی نازک بزن و روغن زیتون تصفیه‌شده یا سبک انتخاب کن، چون کمتر دود می‌کند.

    > Safety: دستکش فر بپوش. طبقه‌ی فر را فقط کمی بیرون بکش تا پیتزا را رویش بلغزانی، و هیچ‌وقت به سطح پخت دست نزن؛ تا مدت زیادی بعد از خاموش کردن فر هم داغ می‌ماند.
11. **بپز**
    {{ recipes.styles.neapolitan.bake.time_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.time_min.range.1 }} دقیقه با گرمای بالا و پایین بپز. در {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخرِ همین زمان، گریل را روشن کن تا روی پیتزا و حاشیه رنگ بگیرد. کنار فر بمان و حواست به پیتزا باشد. پیتزا روی هم هیچ‌وقت نباید بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه زیر گریل بماند. اگر از کاغذ روغنی استفاده می‌کنی، گریل را روشن نکن، مگر اینکه روی بسته نوشته باشد ایمن است.
    > Why: فر {{ recipes.styles.neapolitan.bake.temp_c.value }} درجه از بالا گرمای کافی نمی‌دهد. فر واقعی ناپولیتن خیلی داغ‌تر است، پس گریل بخشی از آن گرما را جبران می‌کند.

    > Tip: پیتزا وقتی آماده است که حاشیه پف کرده و لکه‌های قهوه‌ای تا تیره دارد و کفش سفت شده است. پیش از اینکه لکه‌ها سیاه شوند، پیتزا را بیرون بیاور.
12. **پیتزا را دربیاور**
    پیتزا را با کفگیر یا با دستکش فر بیرون بیاور. اگر دوست داری، ریحان تازه و کمی روغن زیتون رویش بریز.
13. **برای پیتزای دوم صبر کن**
    فر را دوباره روی گرمای بالا و پایین بگذار. {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.0 }} تا {{ recipes.styles.new_york.practice.second_pizza_wait_min.range.1 }} دقیقه صبر کن تا سطح پخت دوباره داغ شود. تا آن موقع روی چونه‌ی بعدی پوشیده بماند و فقط بعد از آن بازش کن.
    > Why: خمیری که روی تخته یا کاغذ معطل بماند خیس می‌شود و می‌چسبد.

## عیب‌یابی

- **حاشیه پف نکرد.** موقع باز کردن چونه روی حاشیه فشار آورده‌ای، یا خمیر به اندازه‌ی کافی ور نیامده بود. فقط وسط را فشار بده و به حاشیه دست نزن.
- **کف رنگ نگرفت یا نرم ماند.** سطح پخت به اندازه‌ی کافی داغ نبود. آن را کامل {{ recipes.oven.preheat_min.range.1 }} دقیقه داغ کن.
- **روی پیتزا کم‌رنگ ماند ولی کفش رنگ گرفت.** سطح پخت را یک طبقه بالاتر بگذار و {{ recipes.styles.neapolitan.bake.grill.last_min.range.0 }} تا {{ recipes.styles.neapolitan.bake.grill.last_min.range.1 }} دقیقه‌ی آخر گریل را روشن کن.
- **حاشیه یا روی پیتزا زیر گریل سوخت.** گریل را مدت کوتاه‌تری روشن بگذار. روی هم هیچ‌وقت بیشتر از {{ recipes.styles.neapolitan.bake.grill.max_min.value }} دقیقه روشنش نکن.
- **خمیر جمع می‌شود.** گلوتن سفت است یا خمیر سرد است. بگذار {{ recipes.styles.new_york.practice.shrink_rest_min.range.0 }} تا {{ recipes.styles.new_york.practice.shrink_rest_min.range.1 }} دقیقه استراحت کند.
- **خمیر پاره می‌شود.** یا سرد است یا گلوتنش ضعیف است. بگذار استراحت کند، یا سوراخ را با یک تکه‌ی کوچک خمیر وصله کن.
- **بوی تند الکل یا ترشی می‌دهد.** خمیر زیادی ور آمده. دفعه‌ی بعد مخمر کمتری بریز یا زمان ور آمدن را کوتاه‌تر کن، به‌خصوص در اتاق گرم.
- **خمیر خیلی چسبناک یا خیلی سفت است.** قسمت‌های «خمیر چسبناک است» و «خمیر خشک است» را در بخش «ورز دادن» صفحه‌ی دستور نیویورکی ببین.

## قوانین اصلی چه می‌گویند

پیتزای ناپولیتن اصل قوانینی دارد که «انجمن پیتزای اصیل ناپلی» تعیین کرده است؛ انجمنی در ناپل که از پیتزای اصل محافظت می‌کند. این راهنما از واقعیت‌های زیر استفاده می‌کند. این‌ها فقط برای اطلاع‌اند و لازم نیست پیتزای خانگی تو از آن‌ها پیروی کند.

- **تخمیر:** روی هم {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_ferment_h.range.1 }} ساعت. قوانین دمایی تعیین نمی‌کنند. در ناپل خمیر در دمای اتاق می‌ماند.
- **چونه و اندازه:** چونه‌ی {{ recipes.styles.neapolitan.ball_g.range.0 }} تا {{ recipes.styles.neapolitan.ball_g.range.1 }} گرمی و پیتزایی با قطر {{ recipes.styles.neapolitan.practice.avpn_diameter_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_diameter_cm.range.1 }} سانتی‌متر. در این راهنما می‌توانی قطر {{ recipes.sizes.0.diameter }}، {{ recipes.sizes.1.diameter }} یا {{ recipes.sizes.2.diameter }} سانتی‌متر را انتخاب کنی. برای وزن هر چونه، «مجموع خمیر» را در کارت «مواد لازم» بر تعداد پیتزاها تقسیم کن. چونه‌ی کوچک‌ترین اندازه کمی از حداقل قوانین اصلی سبک‌تر است و چونه‌ی بزرگ‌ترین اندازه کمی از حداکثر آن سنگین‌تر.
- **حاشیه:** {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_rim_cm.range.1 }} سانتی‌متر.
- **فر:** {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_oven_c.range.1 }} درجه و پخت در {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.0 }} تا {{ recipes.styles.neapolitan.practice.avpn_bake_s.range.1 }} ثانیه. فر خانگی به این دما نمی‌رسد.
